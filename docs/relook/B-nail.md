# B · 钉子派：砍成"再来一次"键

病不在品类，在范围与摩擦：一窗三事＝一事不成。P0 只留一动作（复制走人）、一场景（又撞同一堵墙）、一循环（用→存→再来）。

**一、给谁、哪一秒（Q1）**
周三 15:41，你本人。npm run dev 崩了，8080 被僵尸进程占着；你记得三天前在另一目录解决过，却想不起那串 netstat/taskkill 全写法——查浏览器、问 AI 都要复述，太费。你按 Ctrl+Alt+P：首屏第一行＝"上次（周一）你杀掉占 8080 的进程"，下即当时的完整命令。Enter 复制→回终端粘贴回车→服务起来了。6 秒，没说一个字。
明天为什么还来：占端口/权限/起服务这类墙以周为周期重复；它不要求你记住任何事，只要求你重复生活——每次复制都是给下次埋的钩子。

**二、凭什么替代不了（Q2）**
AI 答通用问题，你要"自己验证过的那条"——它没有你的行为账本，你也不给监听权；Raycast 类做行为预测靠常驻剪贴板/钩子，正是已裁掉并触发杀软的禁区。缝隙＝零权限行为记忆：只读自己的终端历史＋显式读一次剪贴板，把"上周干成过什么"排到面前。代价＝让出"搜命令"红海，我砍。

**三、砍 N1，不止 N1（Q3）**
整砍 N1"用话找回"：它是抽屉病的发动机（全卡加权检索＋预测＝低配 Raycast），更是回忆仪式——先想得起"有卡"才按，故月开两次。真高频是"记得干成过、忘了全写法"，不需说话，要排序。打字只留子串兜底，purpose 加权/意图层/同义词典后置。N2 两字段表单→"粘贴即存"副作用；N3 三行卡面/危险色/人工标注→"只判红"确认门（还 S0 债，零新增）。

**四、P0 动作流（Q3）**
Ctrl+Alt+P → "再来一次"（置顶 1＋备选≤5）→ ↑↓ → Enter＝复制 → 自隐。≤3 键零打字；列表没有→子串搜→仍无→"复制这行存下?"（预填剪贴板）Enter 即存。全产品一窗一框两键。

**五、冷启动（Q4）**
装后唯一向导：导入终端历史（PS5 PSReadLine；PS7/CMD 跳过），剔口令/token/私钥，频率去重 Top-30，当日即有自己真跑过的命令，零写卡。日常蓄水＝一次复制＋一次热键：每次唤起显式读剪贴板一次，读后即弃、零落盘、可关，像命令且非敏感才提示存下。授权：首启一行知情同意；读取计入今日流水；读取面唯一入口。
