## 一、终裁结论

> **v4"回忆式命令抽屉"正式出局（四路一致 + 市场实证）。新方向 = "行为记忆 + 现场"：不让你想起和搜索，把你上次干成过的、这次卡住的，在按热键的 3 秒内送到手边。**
> 落地形态：**最小真机试点 exe（v5-pilot）**，老板本人 + 1 名同行，真 Windows，2 周。过生死线 → 再定 v5 规格；不过 → 作废归档，预算还给真问题。

## 二、裁决明细

### 共识（四路 + 证据，全部采纳）
1. **回忆式抽屉（v4 P0）不可为方向**：D 实证——通用"查命令"已被 AI 免费接管并直达终端（Copilot CLI GA / AI Shell / Azure Copilot 生成脚本），"热键+搜索+复制"抽屉被做透（Raycast 2025-11 入 Windows、uTools 快命令插件）。A/B/C 一致。
2. **零监听红线一步不退**：D 实证杀软误报真实存在（espanso 被 Defender 报 Trojan、Kaspersky 反复报 Cursor 为 ClipBanker、SAC 拦未签名）——误报源是**监听/读剪贴板行为**与**未签名信誉**，不是托盘/热键本身。
3. **先真机小试点、拿数据再定规格**：四路全票；反对先写大文档（v4 的病之一）。
4. **危险确认门（只判红）保留**：还 S0 债，零新增成本，三路共识（A 亦承认 PS wrapper 一行即得——恰好证明该做）。

### 否决与理由
- **否决 A"停做/降级纯 .ps1"**：A 的攻讦有价值，但结论过度。
  - A 断言"残渣日频趋近 0"与 B/C 假设"频次够"一样**都未被测量**——老板不吵架，用最小 exe 测真数据。
  - A 的"纸面自报计数"有 latent-demand 盲区（工具不存在 → 使用意图不发生），会测出假阴性；最小 exe 试点成本相当、产出的是真实行为。
  - A 砍托盘 = 砍掉"3 秒取件"的唯一体验优势；托盘≠监听（见共识 2），无监听无网络的托盘热键不在同类误报风险。
  - **采纳 A 的纪律**：冻结 v4 大开发、先小验证、设硬性关闭线。
- **否决 C 独占主线**：C 的"报错现场"翻案有诚意（c 不翻案、a 有条件翻案、b 复制手势代授权），但 C 自己承认最大翻车点="错八成是首次新错 → AI 完胜"，且依赖剪贴板读取（杀软风险残余、需授权）。降为第二入口，不独占试点主线。
- **v4 现状不维持**：打回三条（无不对称、冷启动靠先写卡、样本 0）无新证据翻案。

### 方向裁决（B 主干 + C 第二入口）
- **选 B 为主干的理由**：① 机制零权限面最小——核心价值**不读剪贴板内容**即成立，杀软风险最低；② 数据已在用户自己账上（终端历史 / copyCount / lastUsedAt）——VISION 调研自己写过的最高频热需求"几天前用过的那条今天忘了全写法"正是此场景；③ "再来一次"不需要用户组织语言、不需要先想起有卡，行为成本趋近零；④ 场景="又撞同一堵墙"（占端口/权限/起服务/依赖冲突），以周为周期真实重复。
- **C 不弃，降为试点第二入口（默认关）**：采纳 C 自己的"数据放行"执行建议——先粘贴式形态攒一周真实数据，剪贴板显式读取作为默认关开关，由数据放行。零监听红线一步不退。

## 三、v5-pilot 试点规格

### 用户动作流（一窗一框，≤3 键）
1. 干活卡壳/要重做 → `Ctrl+Alt+P`
2. 首屏 = **"再来一次"**：置顶 1 条 + 备选 ≤5（排序 = 最近干成过 / 终端历史频率 / 已采纳卡）
3. ↑↓ 选 → `Enter` = 复制 → 自隐回现场
4. 打字子串兜底（不组织语言，只过滤）；仍无 → "把这行存下?"（预填剪贴板，`Enter` 即存）
5. 复制时若命中 high/critical → 确认门（只判红，不判绿）

### P0 范围（最小 exe）
- 再来一次列表 + Enter 复制 + 子串过滤
- 终端历史导入 Top-N 冷启动（剔除口令/token/私钥；PS5 PSReadLine；PS7/CMD 跳过）
- "粘贴即存"蓄水（默认开但**明示可关**；显式读剪贴板一次，读后即弃、零落盘）
- 危险确认门（只判红）
- 第二入口"报错即查"（默认关；粘贴式先行，由一周数据决定是否放行剪贴板读取）
- 埋点最小化：本地 metrics（唤起/采纳/Esc/自隐）——**先有真数据，再谈指标页**

### 明确不做（试点内）
purpose 检索加权 UI · 卡面三行 UI · 生命周期衰减（30/60/90）· 首屏预测标注 · 导入向导 UI（最小可用即可）· 设置页 UI。**以上全部留资产，试点过线后按需回归。**

### 生死线（硬，不可二轮）
| 判定 | 线 |
|---|---|
| ✅ 过 | 连 5 个工作日日均唤起 ≥5，且 唤起→复制中位 ≤10s，且 零打字直接采纳 ≥40% |
| ❌ 死 | 连 3 日零唤起；或第 2 周末未达上述线 → **作废归档**（走 A 派关闭路径），不再二轮 |
| ⚠️ 副测 | 危险确认门 100% 在岗无绕过；Defender/Smart App Control 零拦截；End-to-End <8s |
