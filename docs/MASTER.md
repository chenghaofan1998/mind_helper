# Command Pocket 方案 v2 · 主纲

> 一页读完。详细执行见 docs/MVP.md。与旧文档冲突时以本文为准。

## 是什么

本地优先的个人行动知识库。按**产品**组织，小窗 3 秒给出可复制的答案。

## 用户怎么用（一天的主循环）

```
热键/托盘 随时唤起/隐藏小窗 → 选产品(Linux/Codex/…) → 首屏先给"最该记的 N 条"(个人频率×主流热度×收藏)
→ 搜不到再搜 → 回车复制答案 → 走人
```

## 数据全链路（核心心智模型）

```
输入 ──→ 整理 ──→ 存储 ──→ 检索输出
何时: 主动粘贴/查询   何时: 收录时       何时: 每次查询
什么: URL/文件/长文    什么: 标准 JSON 卡 什么: 卡片(可复制)
                        给谁: 规则(默认)   给谁: 关键词→语义→LLM
                              智能体(兜底)
```

## 模型（两样东西）

**Profile = 一个产品**，声明 4 件事：① 内容空间 ② 接受什么输入 ③ 答案怎么展示/复制 ④ 用几级检索。存 `profiles.json`，后台可改，不写死在代码。

**Card = 一条知识**：`id / product / title / aliases(中英) / kind / body / desc / tags / source / risk / fav / time`

kind = 命令 | 提示词 | 步骤 | 要点 | 警告 | 攻略 | 数据 | 文档

## 输入 → JSON（关键管道，详见 MVP.md）

```
原料(URL/文件/长文/命令) → 识别类型 → 提取纯文本 → 规则结构化 → 校验
   ├─ 通过 → JSON 卡预览
   └─ 低置信/失败 → 智能体(LLM 按 Profile 模板输出 JSON，校验重试1次) → 预览
预览(人审可改) → 确认 → 入库 → 小窗立即可查
```

## 三级检索（降级不阻塞）

1. **关键词**：分词+中英别名+打分（本地，永远在线）
2. **语义**：embedding 余弦（智谱等，向量本地缓存；配 key 启用）
3. **LLM 兜底**：32B 级（ollama/API 小模型，可选）——未命中时生成建议卡入草稿

## 界面（沿用现状，不改职责）

托盘（入口）· 小窗（唯一日常面：产品切换+首屏推荐+搜索+预览+复制，全局热键唤出/隐藏）· 后台（导入/卡片/Profile/设置）

## 铁律

1. 主交付 = 现有 native C#，只演进不重写；单文件按模块拆
2. AI 全走 HTTP provider（智谱/OpenAI 兼容/ollama），不引 Python
3. 只做产品型 Profile，不做全局聚合
4. 数据纯本地；AI 只发必要片段，可一键关
5. 双语靠 aliases+自维护词表，不靠翻译服务
6. 危险操作复制前确认；入库永远先预览后保存（无黑箱）

## 不做（v2）

全局聚合 · 账号/同步/Web · 动态抓取增强 · 快捷键实时教程

## 路线（每阶段可运行、不丢数据）

| 阶段 | 干的事 | 过 |
|---|---|---|
| P1 | Card 新模型 + 数据迁移(带备份) + 别名 + 首屏推荐 | 旧卡不丢，双语可查 |
| P2 | Profile 化 + 管理 UI + 产品切换器 + 全局热键 | 后台可管 Profile，切换生效 |
| P3 | 检索②③ + 命中角标 + 空结果引导 | 无 key 可用，有 key 更聪明 |
| P4 | 输入→JSON 智能体管道 + 风险扩展 | 任意原料成卡，先预览 |
| P5 | 视觉打磨（推荐调优、动画、明暗色） | 体验顺滑 |

MVP = P1 + P2 + P4（规则管道）+ 检索① + 首屏推荐 + 全局热键。详见 MVP.md。
