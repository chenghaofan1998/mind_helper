# Command Pocket MVP 详案

> 主纲见 MASTER.md。本文只回答五件事：MVP 做啥、流程怎么走、首屏推什么、原料怎么变 JSON、长什么样。

## 1. MVP 范围

**做**：产品切换 · 首屏推荐 · 双语关键词检索 · 全局热键唤出/隐藏 · 原料(URL/文件/长文/命令)→JSON 卡(规则+智能体兜底) · 预览后入库 · 复制(危险确认)
**不做**：语义检索(留 P3)、LLM 兜底检索(留 P3)、视觉打磨(留 P5)

## 2. 三个主流程（何时输入 / 输入什么 / 输出什么）

### 流程 A · 日常查询（小窗，用户在干活的间隙）

```
用户何时唤起   卡壳/想不起时，全局热键唤出（再按隐藏）；托盘菜单亦可
输入什么       通常不用输——首屏已是推荐；要精确就敲一句/命令/中文需求
系统输出       推荐区 + 匹配卡列表 → 选中看明细 → Enter = 复制到剪贴板
命中不了       显示"未收录"+ 一键转流程 B 收录
```

### 流程 B · 收录（后台，看到想留的东西时）

```
用户何时输入   遇到好资料 / 刚学会一条命令 / 手头有 URL、文件、长文
输入什么       任选：URL ｜ 文件(TXT/MD/HTML) ｜ 粘贴文本 ｜ 直接填卡
系统输出       标准 JSON 卡预览（可逐条编辑）→ 用户确认 → 入库(cards.jsonl)
入库后         小窗该产品下立即可查（流程 A 闭环）
```

### 流程 C · 产品管理（后台，引入新产品时）

```
用户何时输入   要用新工具/新领域时
输入什么       Profile 四件套：名字/图标 + 内容空间 + 输入说明 + 展示复制偏好
系统输出       新产品出现在小窗切换器，此后 A/B 都在它的上下文里
```

## 3. 首屏推荐 & 前台热键（前台体验，本轮新增）

### 推荐：打开小窗先看到"最该记的 N 条"（不用搜）

三个信号加权，**全部数据本地可算**：

```
推荐分 = 0.4 × 个人频率 + 0.35 × 主流热度 + 0.25 × 收藏/重要
         │              │                │
         │              │                └ 用户标星 + 产品内"重要"标记(如危险项)
         │              └ 随库预置的"各产品默认 Top"权重（seed，随版本更新，不碰用户数据）
         └ 近 30 天复制次数(时间衰减)，新卡无数据按产品内均值
```

- 新产品刚装、无个人数据 → 纯主流热度排前几名，让用户马上有得看；
- 用得越久，个人频率占比逐渐接管排序——推荐越来越像你自己；
- 收藏（fav）额外置顶区。

数据：卡片增 `copyCount` / `lastUsedAt`（每次复制 +1 即记）；热度权重存 seed，不动用户库。

### 热键：小窗随叫随到、随叫随走

| 键（可配置，默认） | 动作 |
|---|---|
| `Ctrl+Alt+P`（示例） | 全局唤出 / 再按隐藏（RegisterHotKey 全局注册） |
| `Esc` | 窗口内隐藏（已有） |
| `` ` `` 或 `Ctrl+Tab` | 循环切换产品（可选，MVP 实现） |

切换产品后推荐区、搜索结果、录入默认产品全部跟随。

## 4. 关键管道：原料 → JSON 卡（你点名的地方）

分工原则：**规则打底（离线免费、毫秒级），智能体兜底（配了 key 才启用，处理规则搞不定的）**。

```
                ┌────────────── 识别器 ──────────────┐
原料 ──────────→│ URL? 文件? 命令? 长文? 空白?      │
  粘贴/拖入      │ 启发式打分：前缀/扩展名/首字符/长度 │
                └──────┬───────────────────────────┘
                       ▼
                ┌────────────── 提取器 ──────────────┐
               URL ──→ 抓取正文清洗                 │
               文件 ──→ 按格式读入                   │
               文本 ──→ 原样                        │
               命令 ──→ 语法高亮+风险初判            │
                └──────┬───────────────────────────┘
                       ▼
                ┌────────────── 结构化器 ────────────┐
               规则抽取（Profile 模板 + kind 分类器）│
                └──────┬───────────────────────────┘
                       ▼ 校验：必需字段? kind 合法? 完整度?
              ┌───── 通过 ─────┐
              ▼                 ▼ 低置信 / 失败
        ┌─── JSON 卡预览 ←──── 智能体兜底 ──────────────┐
        │                   system = Profile 抽取模板    │
        │                   输出 = 仅 JSON(schema 校验)  │
        │                   失败 → 重试 1 次 → 转人工模板 │
        ▼                                                │
   用户确认(可改) ───────────────────────────────────────┘
        ▼
  入库 cards.jsonl → 小窗立即可查
```

产物示例（一条卡 = 一个 JSON 对象，追加写入 jsonl）：

```json
{
  "id": "a1b2…", "product": "Linux",
  "title": "打包压缩目录", "aliases": ["tar", "压缩", "打包", "解压"],
  "kind": "命令",
  "body": "tar -czf x.tar.gz mydir",
  "desc": "把 mydir 压缩成 x.tar.gz",
  "tags": ["archive"], "source": "URL:…",
  "risk": "低", "fav": false,
  "copyCount": 12, "lastUsedAt": "2026-…",
  "createdAt": "2026-…", "updatedAt": "2026-…"
}
```

> MVP 先做轻量智能体：单轮调用 + JSON 校验 + 一次重试。多步 agentic（边查边整理）留 P4 之后，接口预留。

## 5. MVP 长什么样（界面草图）

### 小窗（日常 90% 时间在这里）

```
┌ Command Pocket ───────────────  ─┐
│ [Linux ▾]  🔍 压缩文件夹        │ ← 产品切换 + 搜索
│ ────────────────────────────────── │
│ 📌 为你推荐（个人×主流×收藏）      │
│  tar 打包压缩   git 撤销提交  … │ ← 打开即有货，不用搜
│ ────────────────────────────────── │
│ ╭ tar — 打包/解压 ────[复制] ╮  │
│ │  tar -czf x.tar.gz mydir   │  │ ← body 等宽显示
│ │  何时用: 压缩/传文件夹      │  │ ← desc
│ │  ↑↓ 选择 · Enter 复制      │  │
│ ╰─────────────────────────────╯  │
│ Ctrl+Alt+P 唤出/隐藏 · Esc 藏      │ ← 热键提示常驻底栏
└──────────────────────────────────┘
```

### 后台 · 收录面板（"原料 → 预览卡"的舞台）

```
┌ 后台 ── [导入] [卡片] [产品] [设置] ─────────────┐
│ 原料:  [粘贴 URL/文本…]  [选文件]               │
│ 识别结果: URL · 网页正文 1,842 字                │
│ ─────────────────────────────────────────────── │
│ 预览(可编辑):                          [产品:Linux▾] │
│  标题  打包压缩目录        kind [命令▾]  [重新AI整理]│
│  body  tar -czf x.tar.gz                       │
│  desc  把 mydir 压缩成 x.tar.gz                 │
│  aliases tar,压缩,打包    risk [低▾]            │
│  [×删除本条]  [＋加一条]        [✓ 确认入库 2 条] │
└──────────────────────────────────────────────┘
```

## 0. 实现状态（P1 已完成，待 Windows 编译验证）

- Card 模型收敛为 v2：`product/aliases/kind/body/desc/tags/source/risk/fav/heat/copyCount/lastUsedAt`（旧四套重叠语义字段已删除）
- 存储切 `cards.jsonl`（每行一个 JSON 卡）+ `profiles.json`（产品名单）；写盘原子化（.tmp→.bak）
- v1 自动迁移：发现旧 `cards.tsv` → 转 jsonl → 原文件改名 `cards.tsv.v1-backup-<时间>`；旧 `collections.txt` → 产品名单
- 搜索：产品过滤 + 中英别名 + 术语词典（压缩↔tar 等 15 组）+ 空查询=推荐序（收藏>近期复制>热度）
- 复制即记：BumpCopy 写回 copyCount/lastUsedAt，驱动推荐
- 后台：导入归档/筛选改产品；编辑表单含 产品/类型(kind)/风险/别名/说明；分类管理→产品管理
- SelfTest 扩充至 7 组（清洗/抽取/双语搜索/存储/推荐/备份/v1 迁移）
- 待办：语义检索② / LLM 兜底③ = P3；全局热键 = P2 补；AI 抽取 = P4

## 6. MVP 验收（全勾=完成）

- [ ] 旧 cards.tsv/collections.txt 全量迁移进 jsonl，不丢卡、可回滚
- [ ] 产品切换器生效：换产品 = 换内容 + 换推荐 + 换录入默认
- [ ] 中文需求 ↔ 英文命令都能命中（靠 aliases）
- [ ] URL/文件/长文粘贴后都出"预览卡"，确认才入库
- [ ] 规则抽不出来时，配了 key 的智能体接管并产出合法 JSON
- [ ] 危险命令复制前弹确认
- [ ] 打开小窗先见推荐区：按三信号公式排序，随复制次数变化
- [ ] 全局热键唤出/隐藏生效；产品切换热键跟随（若实现）
