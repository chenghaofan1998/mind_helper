# Command Pocket v3 大胆重想 · 从"答案抽屉"到"反射终端"

> 本文是**提案**，不是定稿。背景：现有 v2（MASTER.md）把"记不住快捷键"做成了"按产品组织的小窗搜索复制库"——可用，但**普通**。本文用 4 个平行思想实验（交互范式 / 知识架构 / 行为设计 / 执行终端 四个透镜，子代理产出，人工收敛）重新回答一个更大的问题：如果 Command Pocket 的目标是当"个人知识库的输出终端"，它应该长什么样。
> 与 v2 的关系：v2 资产（数据/收录管道/界面）全部保留，本文定义**北极星方向**与**分阶段进化路线**。用户拍板后升版并入 MASTER。

---

## 0. 四个透镜的收敛（一句话各执一词，合起来是同一个东西）

| 透镜 | 一句话 | 贡献给总方案的部分 |
|---|---|---|
| 🅰 交互范式 | 最好的快捷键＝没有快捷键：知识在"动作发生的那一刻、那个位置"自己出现 | **感知现场**（律1） |
| 🅱 知识架构 | 内容留在原地，Pocket 只记"哪里有、何时准、怎么用"——是语义路由层不是内容仓库 | **对接存量**（阶段3） |
| 🅲 行为设计 | 记不住不是记忆差，是系统不值得被记住；知识库大多死于"收藏了再也不看" | **用了才算 + 遗忘管理**（律2/律5） |
| 🅳 执行终端 | 知识存在"只能回显的纸上"才会被忘；让卡片可被调用，知识就被用掉、用完长记性 | **输出=动作 + 回写**（律3/律4） |

共同发现：四派没有互相打架，而是各自戳穿了 v2 的一个隐藏前提。v2 的三个"想当然"正是它普通的原因：

1. **用户会记得"去查"**——不会，卡壳的人恰恰想不起入口；
2. **知识＝用户手动喂进来的卡片**——不是，知识本来长在你的笔记/文档/剪贴板历史里；
3. **输出＝给人看/复制**——不够，能执行才叫"用掉"，用了才算真正拥有。

## 1. 总论断：知识反射弧

> **Command Pocket v3 不是数据库，是反射弧**：刺激（正在敲的命令、刚复制的报错、当前窗口）→ 反应（答案自己出现，一步变成动作），中间不经过"想起来去搜索"这个大脑皮层动作。个人知识库是大脑（积累、笔记、文档），Pocket 是它的**输出终端**——把存着的东西，在需要的那一刻变成能直接用的输出。

五个机制律，闭合成一个环：

```
感知现场 ──→ 命中即现 ──→ 一步动作 ──→ 用过回写 ──→ 没用自灭
 (律1)        (律2)        (律3)         (律4)         (律5)
   ↑                                            │
   └──────────── 知识从使用中生长 ──────────────┘
```

**律1 · 感知现场（不问自答）**：前台窗口、剪贴板 = 免费上下文（终端里"正在键入的前缀"拿不到输入缓冲，不作感知源，只作档3 内部机制的近似）。最优雅的查询是没有查询。检索从"你想起才搜"前移到"它看到就备好"。

**律2 · 用了才算拥有（试用态）**：存卡 ≠ 拥有。新卡默认"试用态"，被采纳才转正计分；转正只认两个信号——复制后报了"成了"，或未报错且 3 天内再次复用。收藏(fav)降为**半信号**：延缓衰减、不计转正（与 v2"fav 置顶"共存）。**存了不算，用了才算。**

**律3 · 输出＝一步到动作**：默认输出仍是复制（肌肉记忆不断），但输出能力渐进升级为"可执行"：危险分级 0–4、副作用声明、展开全文预览、确认即执行。知识从"能看见"到"能被用掉"。

**律4 · 用过会长记性（回写）**：反馈不靠打扰——默认采集隐式信号：同卡 3 天内复用＝成了；复制后 10 秒内又搜相似内容＝疑似失败。成功率写回卡，推荐排序被**真实成功率**修正；显式"成了/报错"按钮只放回放页。**让错误成为记忆本身**。

**律5 · 没用自己会消失（遗忘管理）**：全库只有一套**行为钟**（按采纳计）：30 天未用降权 → 60 天归档（不可搜、一键找回）→ 90 天成"待清理候选"。复盘不做定时推送：打开小窗时若待清理候选 ≥3 条，首屏才占一行；删除永远手动且可还原。删除是心智减负，不是损失。

## 2. 交互形态谱（0 → 100，默认停在"克制档"）

不做单一形态，做一条**可调档的干扰—效率曲线**。越往右越激进、打扰风险越高；默认档只在高价值时刻出手。

| 档位 | 形态 | 触发条件 | 打扰 | 状态 |
|---|---|---|---|---|
| 档0 | 小窗+搜索（现 v2 主范式） | 用户主动 | 零 | 永远保留＝显式门 |
| 档1 | **预测队列**：热键唤出时不递空搜索框，先给当前情境最可能的 1–3 条 | 前台窗口×时段 | ≈0 | **v3.0 默认** |
| 档2 | **现场提示**：无焦点浮层/Toast（WS_EX_NOACTIVATE 不抢焦点），采纳＝**采纳热键 Ctrl+Alt+Enter**（把当前提示的答案写入剪贴板，焦点留在原应用）或鼠标点击 | ①复制报错命中卡 ②危险前缀（rm -rf / git push -f…）③白名单窗口＋可靠上下文（窗口标题/剪贴板）高置信 | 低，每天≤N 次，Esc=此场景别再弹 | **v3.1 默认** |
| 档3 | 预置剪贴板＋提示去粘贴（原地注入需跨进程 SendInput/UIA、逐应用适配，管理员终端/中文输入态易废——**记为上限承诺，不进排期**） | 高置信 + 白名单 | 中 | 默认关 |

克制铁律（防止"副驾"变"骚扰"）：

- 只在高价值时刻出手：报错复制、危险前缀、高频卡。猜错的代价≈0（多按一次下箭头），用户教一次（Esc）就记住此场景别再弹；
- 无焦点（WS_EX_NOACTIVATE）、不抢键盘、2.5s 自隐；无焦点窗口拿不到键盘焦点，故"采纳"不依赖焦点——用采纳热键/鼠标点击，键盘焦点始终留在原应用；
- 剪贴板监听防自触发：程序自己写入的内容 500ms 内不引爆监听；
- 托盘一键暂停 / 完全退回档0，永远有"显式门"。

Ctrl+Alt+P 的职能随之升级：不再只是"打开列表"，而是**今日命中回放**（今天弹过什么、你采纳了什么、哪些是噪音→降权）。

## 3. 知识模型：三阶段进化，永不重写

### 阶段1（v3.0，纯加字段）
在现有 cards.jsonl 上追加，向后兼容：

- **情境触发器**：卡片绑定"什么时候会想起它"——报错样例 alias（`failed to push some refs`）、所在窗口/场景（PowerShell/VS Code/微信）、上一步（正要敲 `git commit` 前）。绑定不上情境的卡**不许存**（入库门槛从"内容完整"升为"内容+触发器"）；
- **行为字段**：`failCount / lastPromptedAt / suppressScenes[] / verifiedAt`；
- **场景映射表（v3.0 基建）**：前台窗口→场景，内置种子表（终端/编辑器/浏览器/微信…）+ 后台可编辑 JSON；管理员权限窗口读不到标题时按"未知场景"兜底；
- **迁移兜底**：v2 旧卡没有触发器——迁移时补 trigger＝产品名，整体划入「档0 只读池」：豁免律5 自动衰减（老资产不因迁移被处死），仍可被档1/2 命中；被真实采纳（报成/复用）后进入正常轨道；近 60 天有复制记录的老卡直接按 stable 起算。

### 阶段2（v3.1，生命周期状态机）
卡片不再是一潭死水，而是有生命周期的：

```
draft(草稿) → trial(试用)
trial 7 天零采纳 → 待清理候选(仍可搜、不进推荐、优先被建议清理)
trial 被采纳(报成/3 天复用) → stable(转正)
stable → decay(30 天未用) → archived(60 天·不可搜可找回) → 待清理候选(90 天·只归档不删)
```

- 全库只有一套"行为钟"；"内容过时"是另一回事（failCount + 审计草稿负责），两套信号不混用；
- 升级 = 原卡不动，挂 `supersedes` 指向新卡（保留回滚）；**自动动作只降权、永不删改**，删除永远手动可还原，只在小窗首屏的"一行复盘"出现。

### 阶段3（6–12个月，对接存量知识）
回应"个人知识库输出终端"的完整命题——知识不只来自手动收录：

- 数据模型从"卡片唯一公民"演进为轻量三元组：**Nugget**（原子知识，可不存 body 只存摘要+锚点）/ **Source**（存量锚点：vault 文件路径/标题锚 + **内容指纹**——文件一改锚点即失效重锚，纯"路径+偏移"一改全废；另有 URL、剪贴板历史）/ **Edge**（`equalTo / supersedes / verifiedOn(工具版本) / failedOn(工具版本)`，工具版本也是图节点）；
- 对接源：**Obsidian/本地 Markdown vault 只读索引**（代码块/标题自动成 Nugget 候选，FileSystemWatcher 增量同步）。剪贴板历史已在 v3.0 作为冷启动种子接入，此处只补"持续命中回写"。核心动作是"索引不是收录"——内容留在原地、Pocket 只记"哪里有、何时准、怎么用"；
- **保鲜传感器**：复制后报错 / 点"失效"记 failedOn(工具版本) 扣置信（行为衰减走阶段2 的统一行为钟，这里只管**内容新鲜度**）；LLM（配 key 时）抽样对照官方文档产出"替代草稿"进草稿箱——新旧答案**并行呈现**让用户自己挑，工具永不自我宣判"已失效"；
- Profile（按产品组织）从"数据归属"降级为**视图**（过滤+排序+渲染器），前台窗口自动推断；保留手动覆盖开关（与 v2/MVP"切换产品"的心智兼容）；
- 命中存量段落时高亮"回源"直跳 vault——小窗给答案，笔记给上下文。

## 4. 输出升级：从复制到执行（v3.2，渐进，默认仍是复制）

- 命令/步骤卡加技能字段即升级，不另起炉灶：`params / template / actions(copy|run) / sideEffects(剪贴板|shell|文件|破坏性) / status(draft|trial|stable) / stats(exec/suc/fail)`；
- **安全模型**（延续 v2"危险复制前确认"，升级为分级门禁）：

| 级 | 动作 | 确认策略 |
|---|---|---|
| 0–1 | 纯复制 / 只读 | 一键过 |
| 2 | 写文件 | 预览展开后命令，回车 |
| 3 | 改配置/装包/联网 | 二次确认 + 全命令展示 |
| 4 | 删除/不可逆 | 手输确认词 + 影响清单 |

- 新技能进**见习期**：前三跑强制预览逐条审计，稳才放权；危险词静态检测（rm -rf / drop / format）作独立于模型的二道闸；
- 审计 = 本地 JSONL（时间/技能/展开后全命令/退出码），默认静默、周报汇总；
- 未命中时 LLM 兜底不再吐文本，改吐**技能草稿**，人确认转正——问答消耗变成知识生产；
- **信任坡度自成**：Enter=复制永远不变，运行恒多一步。用户怕的从来不是执行，是没有预演的黑暗执行。

## 5. 北极星指标（怎么知道它真的优雅了）

**主指标**：现场命中采纳率 = 被采纳的卡片条次 ÷ 弹出的卡片条次（一次弹 3 条、用了第 2 条＝分母 3、采纳 1；目标 ≥60%，且趋势上升——系统越用越懂你）。
**次指标**：① 主动搜索占比下降（从"找"迁移到"现"）；② 隐式成功信号（3 天复用）比例；③ 冷启动到首次命中 <1 天（history 导入做减法起步）；④ 手动收录区库容量随使用衰减（活库 vs 坟场；v3.3 导入区不计，避免与增量索引冲突）。
**反指标（红线，均可本地采集）**：提示后 3 秒内关闭率、Esc 率、被永久关掉的场景数（suppressScenes 增长）。无账号本地应用没有"投诉"通道，故用行为代替态度。

冷启动策略（做减法）：第一天不建库——导入终端 history 生成"你大概常用这 10 条"，请用户**删掉用不上的**；首屏即自己的高频，不是空库。

## 6. 里程碑路线（每阶段可运行、不丢数据、可回退）

| 版本 | 干什么 | 过（验收） | 大致周期 |
|---|---|---|---|
| **v3.0 感知与试用态** | 前台窗口感知+场景映射表+档1预测队列（唤出不递空框）；**终端历史导入（PSReadLine 明文可读、密钥脱敏正则）做减法冷启动**；**剪贴板监听基建**（v3.1 报错即推复用同一监听器）；新卡试用态 7 天；隐式成功信号回写（3 天复用=成了） | 开着终端按热键，0 键入命中首条即复制；history 导入产出"常用 10 条"且密钥已脱敏；存一条新卡 7 天零采纳自动进待清理候选；复制后 3 天复用该卡转正 | 2–4 周 |
| **v3.1 现场提示与遗忘** | 档2 现场提示（复制报错即推、危险前缀拦截、白名单+可靠上下文高置信）；采纳热键 Ctrl+Alt+Enter/点击；Esc/托盘教学（suppressScenes）；生命周期 降权→归档→待清理；一行复盘（候选 ≥3 才出现） | 复制一段报错 3 秒内出方案，Ctrl+Alt+Enter 写入剪贴板且焦点不离开原应用；程序自写内容 500ms 不引爆监听；误弹一次 Esc 后同场景不再弹；衰减/归档验收用**内置调试时钟+合成数据**（4–8 周内等不到自然 60 天） | 4–8 周 |
| **v3.2 可执行技能** | skill schema+装配/预览管线（仅 copy/run）+分级门禁+审计 JSONL+见习期；20 张高频卡转正；LLM 兜底改吐技能草稿（3–4 级"影响清单"＝静态启发+人工预填，无沙箱需记录误判边界） | 危险命令静态检测拦截；见习期强制预览；回写成功率修正推荐序；门禁误判率留档 | 8–12 周 |
| **v3.3 对接存量知识** | vault 只读索引（内容指纹重锚）+Source/Nugget/Edge 轻图谱；保鲜审计（配 key，替代草稿并行呈现）；回源跳转；Profile 降视图但保留手动覆盖 | 已有 vault 不改一字即可被检索；文件改动后锚点自动失效重锚；新旧答案并行呈现由人挑；命中率不被噪声淹没 | 6–12 个月 |

每阶段之间：数据兼容（纯加字段/新文件）、上一版本功能照常可用、一键回退。

## 7. 风险与边界（四透镜自攻击的收敛 + 对策）

1. **预测变骚扰** → 默认档只在高价值时刻出手；每天上限；统计猜中率，低于阈值自动收敛为只显 1 条；Esc=此场景别再弹，越用越安静。
2. **老用户失去掌控感 / 受控终端禁钩禁注入** → 显式门（热键/托盘）永存；档位可切、注入默认关；主推"提示+复制"档；原地注入已降级为"预置剪贴板+提示粘贴"（上限承诺，不进排期）。
3. **卡库太小全天零命中（冷启动）** → history 导入做减法起步；从"报错修复"这个确定性场景切入；命中不足自动缩回仅报错模式。
4. **图谱变"只写不读"的虚荣本体** → 不设手工建边入口，边一律进草稿箱待确认；定期清三个月零读取的孤儿节点。
5. **保鲜误杀（正在用的被降级/审计推翻）** → 自动动作只降权不删改；权威判定需 ≥2 独立信号；新旧答案并行呈现，人挑。
6. **隐私 / 无账号的责任边界** → 本地优先即卖点：全离线、白名单可视、可一键停；执行全在本机、模型只产文本草稿；凭证走系统凭据库。

## 8. 结论：下一步做什么

如果只做一件事验证方向：**档2 的"复制报错即推"**——它成本最低（AddClipboardFormatListener 剪贴板监听是 WinForms 一天能做的事，且与 v3.0 冷启动的 history 种子共用基建）、确定性最强（报错→方案是人类最高频的卡壳时刻）、收益肉眼可见（3 秒 0 键入拿到可粘贴的修复），且天然产出一条北极星数据（提示→采纳率）。

方向对了，v3.0 的预测队列 + 试用态 + 反馈回写是紧接着的第二步。执行化（v3.2）与存量索引（v3.3）是有意压后的火箭——先让"反射弧"在手动收录的库上跑顺，再接入更大的大脑。

> 一句话总结：**v2 让"查得到"变快，v3 让"不用查"成为默认**——知识该在动作现场自己冒出来，用了才算拥有，用完会长记性，没用自己消失。
