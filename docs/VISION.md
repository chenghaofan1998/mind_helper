# Command Pocket v3.2 · 从"答案抽屉"到"反射终端"（主纲 · 零监听裁定版）

> **本文是提案，不是定稿。** 演进史：v2 把"记不住快捷键"做成按产品组织的搜索复制库（可用但普通）→ v3.0/3.1 提出"知识反射终端"五律与现场推送（方向对，但被质疑：可行性是否依赖读用户输入）→ **v3.2 经 3 组裁判式评审（调研→提案→挑战→终局打分）裁定**：默认零监听成立、方案需缝合、范围需收缩。本文即裁定后的修正主纲。
> **阅读指引**：本文＝决策主纲；执行细节（可行性矩阵/UX 规格/试点）见 `docs/VISION-EXEC.md`。拍板后并入 MASTER。

---

## 0. 定位（一句话与诚实边界）

> **「要用的那条，现场先到」——剪贴板之后 3 秒的第一站。**

- 竞品全在做"你想起来→去搜"（回忆式抽屉）；我们反过来：人卡在出错现场、还没想起要搜什么时，答案已候着。
- **诚实边界**：不吹"0 击自动推送"，不吹"适配我的环境"——只做**用户主动一步**触发的现场命中（复制报错＝把现场交出去），环境差异靠显式档案而非监听。常驻监听/自动推送/原地注入**整体移出 v3.x**。

## 1. 裁判式评审裁定（3 组 × 调研/提案/挑战 + 终局裁判）

| 方案 | 技术 | 隐私获准 | 解决痛点 | 易用 | 投入产出 | 合计 |
|---|---|---|---|---|---|---|
| 组A 零监听分层 | 6.0 | 8.0 | 6.5 | 6.0 | 7.0 | 33.5 |
| 组B 最小闭环规格 | 6.5 | 9.0 | 6.0 | 6.5 | 5.5 | 33.5 |
| 组C 差异化定位 | 5.5 | 9.0 | 6.0 | 8.0 | 6.5 | 35.0 |

**裁定：无全胜者，路线＝缝合**——借 C 的诚实承诺句与一键闭环、借 B 的可自证读取架构与验收口径、借 A 的档位克制；三家各自的分歧在取舍不在事实（均已源码核验）。

**关键事实（调研实证）**
- 隐私风险主源不是"联网"，而是：**杀软行为误报**（espanso 被 Defender 报毒、clipboardy 被多引擎报毒、Kaspersky 曾把 Cursor 误报为 ClipBanker）、**未签名 exe 信誉**（Smart App Control 拦截）、**企业 DLP 审计**。信任公式＝默认不采 × 敏感来源排除 × 可自证（竞品：Alfred 剪贴板默认关；Raycast 本地加密、内容不出设备、默认忽略密码管理器来源）。
- Windows **没有**剪贴板"授权门"（无 macOS 式 TCC）→ 常驻监听与木马行为同构，**不可自证**——这就是档3/自动推送出局的硬理由。
- "按进程名分桶的 frecency（频率×近因）"是业界通行预测法（Raycast/VS Code/VS 语言服务同构），但进程名桶会被**同 PID 大桶污染**（Windows Terminal 全 tab 同 PID、VS Code 内嵌终端同桶）、窄桶**冷启动无数据**——学习型档1 必须等试点攒够桶数据。
- **三组都没看到的一件事**：最高频的热需求其实是**"几天前用过的那条命令今天忘了全写法"**——数据已在自己账上（copyCount/lastUsedAt），零权限可得，而现推荐对近 30 天任意次数同分，连"再来一次"入口都没有。同时"复制≠用过"：零监听下粘贴是否成功**不可观测**，回写只能记意向。

## 2. 五律（保留，口径修正）

```
唤起即现 ─→ 一步动作 ─→ 用过回写 ─→ 没用自灭
 (律1)       (律3)        (律4)        (律5)
```

- **律1 · 唤起即现（事件式，非驻留）**：只在用户唤起瞬间做**一次**前台窗口元数据采样（进程名），作场景标签与种子置顶，**不学习、不落盘**；学习等试点后有数据。
- **律2 · 用了才算拥有**：新卡试用态，被采纳（复制/执行）才转正；fav 仅延缓衰减。**存了不算，用了才算。**
- **律3 · 一步动作**：默认复制；危险分级 0–4 与确认门在 S0 先还债落地（v0.4 欠账）。
- **律4 · 用过回写（诚实版）**：零监听下粘贴成功不可观测——回写只记**意向信号**（采纳/弃用/Esc/复制后 3 天复用），"成了/报错"靠回放页手动反馈，不假装自动知道。
- **律5 · 没用自灭**：30/60/90 天行为钟（降权→归档→待清理候选），惰性计算不加定时器。

## 3. 读取与授权阶梯（本版核心）

| 级 | 需要什么 | 代表功能 | 授权 |
|---|---|---|---|
| 零权限 | 无（只看自有数据） | 档0 搜索/推荐、"最近再用"栏、试用态/遗忘、危险确认、历史导入预览 | 随装即用 |
| 窗口元数据 | 唤起瞬间 1 次前台进程名 | 档1 场景标签＋种子置顶（事件式，不驻留不落盘） | 设置页告知一次 |
| **一次性剪贴板** | 显式键/托盘触发读 1 次 | **报错即查**（v3.x 唯一内容接触面） | 首次知情同意 |
| 常驻监听 | 持续读剪贴板/钩子 | 0 击推送/自动注入（旧档2 自动版、档3） | **不在 v3.x** |

铁律：**任何读取＝一次用户动作＋一条可见审计**；读后即弃、原文不落盘不入日志；内容接触点收敛为唯一入口。

## 4. 里程碑（缝合版 S0–S3，2–4 周 + 2 周试点）

| 步(周) | 做什么 | 过/不过判定 |
|---|---|---|
| **S0(0.5)** | 基建：热键返回值检查＋第二热键、存储批量写；**危险卡复制确认**（还 v0.4 欠账，零监听下唯一天然显式反馈点） | danger 100% 过门、放弃零写入、SelfTest 绿；否则停 |
| **S1(1)** | 档0 近因强化＋**"最近再用"一栏**；唤起瞬间读 1 次进程名仅作场景标签＋种子表置顶；试用态纯追加字段 | 5 个工作日日均 ≥3 次唤出即复制；假时钟 61 天自测过；否则返工排序，不立项感知 |
| **S2(1–1.5)** | **报错即查**：显式键/托盘 → 读剪贴板 1 次 → 抽错误签名 → 种子＋本地卡 ≤5 候选；只回写"签名→采纳卡 id"自举语料，原文零落盘 | 20 条真错命中 ≥80%、10 条非错 0 候选、剪贴板占用退避 3–5 次静默；否则砍 T2 锁纯档0 |
| **S3(3–4)** | 2 周试点：metrics.jsonl 埋点；**双入口日频测量**（命令回忆 vs 报错即查）；北极星验收 | 四线全过→v3.1 才做学习型档1/提示增强；任一不过→砍预测与推送，锁"档0 强版＋报错即查"形态攒数据，v3.1 重审 |

**后续（试点通过才立项）**：学习型档1（此时才有桶数据）→ 风险警示 → 可执行技能（原 v3.2）→ 存量笔记索引（原 v3.3，需先补 AI 客户端）。

## 5. 北极星指标（可自证口径）

- **主**：**有复制唤起的 Top3 采纳率 ≥60%**（样本 <50 不亮灯——不可自证就不当数字用）。
- **次**：双入口日频与回写率（命令回忆 vs 报错，试点定窄口）；Esc 率、3s 关闭率、被永久关掉的场景数。
- **红线**：任何内容读取路径除唯一入口外不可达（代码审计口径）；原文零落盘。

## 6. 风险与边界（评审收敛）

1. **杀软误报/未签名信誉** → 默认零监听＋单文件＋无网络即自证材料；发布前做 Defender/VT 预检；S2 读取面唯一。
2. **预测被打扰** → v3.x 无自动推送；档1 只做唤出即见的队列，Esc＝此场景别再弹。
3. **冷启动零命中** → 预置种子包兜底；"最近再用"零权限先蓄水；语料经报错即查回写自举，首月命中率明示爬坡。
4. **报错频次错配（低频才是记不住的）** → 双入口埋点后定窄口，不拿报错一个格子赌全程。
5. **正面撞 IDE/终端生态位** → 承认自己是"剪贴板之后 3 秒的第一站"，不抢就地修复场景。
6. **复制≠用过** → 回写口径只记意向＋手动反馈，指标可自证。

## 7. 结论：先做什么

从最不性感处开工：**S0 还账（危险确认）**是任何路线都要先还的债；2–4 周预算压在零权限的"最近再用"与唯一读取面"报错即查"上；学习型档1、自动推送、常驻监听全挡在试点判定之后。**砍的条件只有一条但必须硬执行**：试点未过"有复制唤起的 Top3 采纳 ≥60%（样本 ≥50）"或连续两周日频不足 → 砍全部感知方向，退回更快更全的抽屉（纯档0＋危险门），v3.1 再重审。

> 一句话：**默认零监听、唯一入口、先还账、再蓄水、用数据换后续权限**——信任立得住，北极星从口号变成可证伪的度量。
