# Command Pocket v3.1 · 从"答案抽屉"到"反射终端"（主纲）

> **本文是提案，不是定稿。** v2（MASTER.md）把"记不住快捷键"做成"按产品组织的小窗搜索复制库"——可用但**普通**。本文用 4 路平行思想实验（交互范式/知识架构/行为设计/执行终端）＋红队评审＋源码级可行性核验，重答一个问题：Command Pocket 当"个人知识库的输出终端"，应该长什么样？
> **v3.1 更新**：① 对照 native 源码（3412 行）逐机制核验可行性——全部 v3.0 项为 A/B 级纯系统 API，砍掉键盘钩子方案；② 补易用性决策（回车语义永不变 / 提示缩角不消失 / 灯闪反馈 / 敏感剪贴板红线）；③ 加 2 周试点与判定线。
> **阅读指引**：本文＝主纲（一页级可读性）；完整可行性矩阵 / UX 规格草图 / 试点方案见 `docs/VISION-EXEC.md`。拍板后并入 MASTER。

## 0. 四个透镜收敛成同一个东西

| 透镜 | 一句话 | 贡献 |
|---|---|---|
| 🅰 交互范式 | 最好的快捷键＝没有快捷键：知识在"动作发生的那一刻、那个位置"自己出现 | 感知现场（律1） |
| 🅱 知识架构 | 内容留在原地，Pocket 只记"哪里有、何时准、怎么用"——是路由层不是内容仓库 | 对接存量（阶段3） |
| 🅲 行为设计 | 记不住不是记忆差，是系统不值得被记住；知识库死于"收藏了再也不看" | 用了才算＋遗忘（律2/律5） |
| 🅳 执行终端 | 知识存在"只能回显的纸上"才会被忘；让卡片可被调用，知识就被用掉、用完长记性 | 输出＝动作＋回写（律3/律4） |

v2 的三个"想当然"正是它普通的原因：
1. **用户会记得"去查"**——不会，卡壳的人恰恰想不起入口；
2. **知识＝手动喂进来的卡片**——不是，知识本就在笔记/文档/剪贴板历史里；
3. **输出＝给人看/复制**——不够，能执行才叫"用掉"。

## 1. 总论断：知识反射弧

> **v3 不是数据库，是反射弧**：刺激（刚复制的报错、当前窗口）→ 反应（答案自己出现，一步变成动作），不经过"想起来去搜索"。个人知识库是大脑，Pocket 是**输出终端**。

```
感知现场 ─→ 命中即现 ─→ 一步动作 ─→ 用过回写 ─→ 没用自灭
 (律1)       (律2)       (律3)        (律4)        (律5)
```

**律1 · 感知现场**：前台窗口、剪贴板＝免费上下文（终端"键入前缀"拿不到缓冲，不作感知源）。最优雅的查询是没有查询。
**律2 · 用了才算拥有**：新卡默认"试用态"，被采纳才转正；转正只认两个信号——复制后报了"成了"，或未报错且 3 天内再次复用。收藏(fav)＝半信号：延缓衰减、不计转正。**存了不算，用了才算。**
**律3 · 输出＝一步到动作**：默认仍是复制（肌肉记忆不断），渐进升级"可执行"：危险分级 0–4、副作用声明、预览后执行。
**律4 · 用过会长记性**：反馈不靠打扰——隐式信号：同卡 3 天复用＝成了；复制后 10 秒内又搜相似＝疑似失败。成功率写回卡，推荐被**真实成功率**修正；显式反馈只放回放页。**让错误成为记忆本身。**
**律5 · 没用自己会消失**：一套**行为钟**：30 天未用降权 → 60 天归档（可找回）→ 90 天"待清理候选"。复盘不做定时推送：待清理 ≥3 条时首屏才占一行。删除永远手动可还原。

## 2. 交互形态谱（默认停在"克制档"）

| 档 | 形态 | 触发 | 打扰 | 状态 |
|---|---|---|---|---|
| 0 | 小窗+搜索（现 v2 主范式） | 用户主动 | 零 | 永远保留＝显式门 |
| 1 | **预测队列**：唤出即有"此刻你可能要"1–3 条置顶（复用现有空查询推荐＋场景推断），默认高亮第 1 条 | 前台窗口×时段 | ≈0 | **v3.0 默认** |
| 2 | **现场提示**：贴前台窗口右上外侧 8px 轻浮层（标题＋答案首行，宽 360）；2.5s 后缩成右下角 12px 呼吸点（可悬停恢复），不硬消失 | ①复制报错命中→给方案 ②复制危险内容→**警示** ③白名单窗口＋可靠上下文高置信→给答案 | 低，每天≤N 次 | **v3.1 默认** |
| 3 | 预置剪贴板＋提示去粘贴（原地注入＝上限承诺，不进排期） | 高置信＋白名单 | 中 | 默认关 |

**采纳**＝采纳热键 `Ctrl+Alt+Enter`（写入剪贴板＋托盘灯闪 100ms，无弹窗、焦点不离开原应用）或鼠标点击。`Ctrl+Alt+P` 升级为**今日回放页**：时间线（每条右缘 [采纳][×噪音]）＋一行统计＋噪音区一键"教它别再弹"。

**易用性决策（每条带为什么）**
- **回车语义永不变**：Enter 永远＝复制高亮项。变语义＝教用户重学，是最大流失点。
- **永不空屏**：无预测退回 v2 推荐区，空库给一行灰字。空屏＝一次失败体验，会被记住。
- **提示缩角不消失**：硬消失会掐断"刚读到一半"；呼吸点保留找回入口又不占视线。
- **反悔三层**（托盘第一组，≤2 击）：场景静音（Esc/×，60 天解封）→ 暂停提示（退档1，图标变灰）→ 退出。逃逸成本≈0，用户才敢开自动提示。
- **出手门槛**：提示价值 ≥ 3× 打扰成本才出手——报错即推 > 危险警示 > 白名单猜测。
- **敏感剪贴板红线**：密码/私钥/token 命中一律**不提示、不计数、不落日志**，监听内容只留内存。

## 3. 知识模型：三阶段进化，永不重写

**阶段1（v3.0，纯加字段，后向兼容）**：情境触发器（报错样例 alias、所在窗口场景、上一步；绑不上触发器不许存）· 行为字段（`failCount/lastPromptedAt/suppressScenes[]/verifiedAt`）· 场景映射表（内置种子表＋后台可编辑）· **迁移兜底**（旧卡补 trigger＝产品名入「档0 只读池」豁免衰减，被真实采纳后进正常轨道；近 60 天有复制记录者直接按 stable 起算）。

**阶段2（v3.1，生命周期）**：`trial →(7 天零采纳) 待清理候选`；`trial →(报成/3 天复用) stable`；`stable → decay(30 天) → archived(60 天) → 待清理候选(90 天，只归档不删)`。全库一套行为钟；"内容过时"另由 failCount＋审计草稿负责，两套不混用。升级挂 `supersedes` 指向新卡；**自动动作只降权、永不删改**。

**阶段3（6–12 个月，对接存量知识）**：轻量三元组 **Nugget/Source/Edge**（Source 锚点用路径/标题锚＋**内容指纹**，文件一改即重锚）· 对接 **Obsidian/Markdown vault 只读索引**（剪贴板历史已在 v3.0 作种子）· **保鲜传感器**：复制后报错记 `failedOn(工具版本)` 扣置信；LLM（配 key）抽样对照官方文档出"替代草稿"，新旧**并行呈现**由人挑 · Profile 降级为**视图**（前台自动推断，保留手动覆盖，与 v2 心智兼容）· 命中存量段落可"回源"直跳笔记。

## 4. 输出升级：从复制到执行（v3.2，默认仍是复制）

技能字段：`params/template/actions(copy|run)/sideEffects/status(draft|trial|stable)/stats(exec/suc/fail)`。

| 级 | 动作 | 确认 |
|---|---|---|
| 0–1 | 纯复制/只读 | 一键过 |
| 2 | 写文件 | 预览展开后命令，回车 |
| 3 | 改配置/装包/联网 | 二次确认＋全命令展示 |
| 4 | 删除/不可逆 | 手输确认词＋影响清单（静态启发＋人工预填） |

- **先还 v2 欠账**：危险卡复制确认（现 `CopySelected` 直写剪贴板、风险标注不拦截——v3.1 顺带补上）；
- 新技能进**见习期**：前三跑强制预览审计；危险词静态检测作独立于模型的二道闸；
- 审计＝本地 `audit.jsonl`（时间/技能/展开后命令/退出码），默认静默、周报汇总；
- 未命中时 LLM 兜底改吐**技能草稿**，人确认转正——问答消耗变成知识生产；
- **信任坡度自成**：Enter＝复制永远不变，运行恒多一步。

## 5. 北极星指标

**主**：现场命中采纳率＝被采纳的卡片条次 ÷ 弹出的卡片条次（弹 3 条用第 2 条＝分母 3 采纳 1；目标 ≥60% 且上升）。
**次**：① 主动搜索占比下降 ② 隐式成功（3 天复用）比例 ③ 冷启动到首次命中 <1 天 ④ 手动收录区库容量随使用衰减（v3.3 导入区不计）。
**反（红线，本地可采）**：提示后 3s 关闭率、Esc 率、被永久关掉的场景数（suppressScenes 增长）。无账号无"投诉"通道，用行为代替态度。

**冷启动（做减法）**：导入终端历史生成"你大概常用这 10 条"，请用户删掉用不上的；首屏即自己的高频，不是空库。

**v3.0 收尾＝2 周试点关卡**（判方向，判定线见执行附录 E）：过了续做 v3.1；不过砍预测队列，退回"仅报错即推＋手动收录"再重审。

### 可行性速览（源码逐机制核验，矩阵见执行附录）
1. v3.0/v3.1 全部核心机制评级 **A/B（纯系统 API，无新依赖）**，2–4 周现实；
2. **唯一砍掉**：键盘钩子"危险前缀拦截"（C 级：杀软误报/逐应用不可控）→ 换三件套：复制危险内容警示＋危险卡复制确认＋v3.2 执行静态检测；
3. **两个代码事实**：危险复制确认是 v2 欠账（先补）；当前无 AI HTTP 客户端（P4 未落地）→ v3.3 前置一个 HttpWebRequest 最小封装（约 1 天），保鲜审计/技能草稿共用；
4. **开工前两个小基建**：`RegisterHotKey` 补返回值检查＋第二热键；`CommandStore` 加批量更新（回写不碎写盘）；
5. **回滚有保障**：JSON 读卡宽容（未知 key 忽略）→ 新字段纯追加，旧程序读新库不崩。

## 7. 风险与边界

1. **预测变骚扰** → 高价值时刻才出手；每天上限；猜中率低于阈值自动收敛为只显 1 条；Esc＝此场景别再弹，越用越安静。
2. **失去掌控感/受控环境禁钩** → 显式门永存；档位可切；主推"提示＋复制"档。
3. **冷启动零命中** → history 导入做减法；从"报错修复"确定性场景切入；命中不足自动缩回仅报错模式。
4. **图谱变"只写不读"的虚荣本体** → 不设手工建边入口，边进草稿箱待确认；定期清零读取孤儿节点。
5. **保鲜误杀** → 自动动作只降权不删改；权威判定需 ≥2 独立信号；新旧答案并行，人挑。
6. **隐私/责任边界** → 本地优先即卖点：全离线、白名单可视、可一键停；执行全在本机、模型只产文本草稿；敏感剪贴板零落盘。

## 8. 结论：下一步

第一步仍是**"复制报错即推"**（AddClipboardFormatListener 一天可通，与 history 种子共用基建，天然产出北极星数据）。开工顺序：两个小基建 → 档1＋试用态＋剪贴板监听（v3.0）→ **2 周试点关卡**过则续 v3.1，不过则收缩重审。执行化（v3.2）与存量索引（v3.3）有意压后——先让"反射弧"在现有库上跑顺，再接入更大的大脑。

> 一句话：**v2 让"查得到"变快，v3 让"不用查"成为默认**——知识在动作现场自己冒出来，用了才算拥有，用完会长记性，没用自己消失。
