## 0. 一句话主形态

> **热键即达的"个人命令口袋"：把记不住、怕敲错的命令，按自己的话记一笔；此后无论忘得多干净，一句话或几个碎片就能找回、看清风险、敢复制敢按。**

口径收窄：**只做"通用 AI 答不出的个人/私有命令"**（自己的别名、公司特有命令、个人语境）；通用公开命令不预录，交给外部 AI——否则免费替代就在门口。

## 2. 需求全景（合并去重）

**P0——缺它产品不成立**
- **N1 用「话」找回**：做到一半/深夜救急、说不出命令名 → 输入一句目的"查端口被谁占着"或碎片"带 l 的" → 对的卡浮第一屏 → 不离开现场 30 秒认出"就是它"，还说得出它干嘛。
- **N2 当场留住、按我的话说**：刚经演示/试对弄明白 → 几秒内用自己的话记一句 → 日后按我的语境重现 → 一两周后同类时刻半分钟命中，不再考古。
- **N3 看得懂、敢决定**：命令在眼前却怕敲错收不回 → 看到它动什么/改删什么/能否还原/危险色 → 看完立即敢按或敢不按，零试错零悬心。

**P1——很重要**
- **N4 要结果不要说明书**（周姐）：只想把照片变小发出去 → 拿到直接可用的成品，或会的人配好一次、此后按一下就成。**张力项：若她算核心用户，P0 要重写——须拍板。**
- **N5 自己做时照点就行**：无成品无人替 → 一步一看、无需理解与决策 → 零基础无人帮，一步不卡办完。

**P2——锦上添花**
- **N6 上真机前无后果走通**：第一次心里没底 → 最坏只是重来 → 从未真正损失过东西。

## 3. 三条底层需求（所有场景的根）

1. **被记住，不是被教会**——三人都要记忆外包，没人要知识进脑；
2. **先有敢，才有会**——根子都是"后果由我背"，要安全感，知识只是载体；
3. **体面**——忘＝失格。产品须让找回像"我本来就会，只是没带在手边"。

## 4. 张力与待拍板

1. **快 vs 敢**（N1 要 30 秒回岗，N3 要读完风险才敢动）：默认直达最可能那张，风险强弱由用户自定；
2. **成品 vs 命令文本**（N4 与"交付一行字"互斥）：**周姐是否核心用户？裁判按"非核心"作答（P1），须你拍板**；
3. **个人话 vs 通用话**：个人说法优先命中，通用说法兜底纠错，不让两套各说各话；
4. **首发范围**：裁判裁"2–4 周内核不建 Logseq 桥、不预埋 AI"——与你上一轮定的"Logseq 双向"边界冲突，实为**排期**问题：先打内核还是双轨并行？须你拍板。

## 5. 解法内核（2–4 周，按需求反推，非自嗨）

- **记一笔**（解 N2）：复制/学会后同窗切换，只填两字段——我刚用它干什么（原话）＋何时还会用；超两字段即失败。记下即成卡。
- **说人话搜**（解 N1）：每卡强制带"目的句"，检索＝命令名＋目的句＋别名加权；首屏最可能一张＋备选 ≤3；支持碎片（"带 l 的"）与中文意图。
- **三行风险**（解 N3）：卡面固定三行——动什么 / 改删什么 / 能否还原＋危险色；**规则只判红、探不到显标"无法探测"、绝不判绿**（防假安全）；确认文案＝"粘贴执行前再看一眼"（与险情发生点对齐）。
- **零命中出口**：明示无卡＋一键转"记一笔"（首卡零命中是致命场景，必须留出口）；空态挂"最近最该记 N 条"保日频（承接 v0.4 推荐）。
- 明确不做（内核期）：执行主体、周姐成品化分发、跨设备、AI 兜底、Logseq 桥（单列排期）。

## 7. 终裁条件与顺序

挑战者四项修正（零命中出口 / 只判红不判绿 / 伪承接拆出 / 空态保日频）**全部采纳**。
