## 1. 产品是什么

**Command Pocket = 本地优先的个人"行动知识口袋"**：一个热键即达的小窗，把你记不住、怕敲错的命令与操作知识，按**自己的话**存下、找回、看清风险后取走。它不做第二个大脑——深度积累在你的 Logseq，它只做"大脑够不着时伸到手上的那一页"。

- 形态：Windows 托盘常驻 + 小窗隐藏/热键唤出（`Ctrl+Alt+P`）
- 本地优先：零监听、无账号、数据纯本地 `cards.jsonl`；AI 仅可选 HTTP（配 key 才启用）
- 主交付：`native/CommandPocketNative.cs` 单文件 C# WinForms，纯 csc 编译，无第三方依赖

## 2. 服务谁 / 核心需求（P0）

| 用户 | 一句话画像 | P0 需求 |
|---|---|---|
| 小周·多工具重度用户 | 十几工具各记一半，只有画面说不出名 | **N1 用「话」找回**：说不出命令名，一句目的（"查端口被谁占着"）或碎片（"带 l 的"）就让对的卡浮首屏，30 秒认出即走 |
| 王默·老手救急 | 会过但忘了，怕在 root 敲错 | **N2 当场留住**：刚弄明白时用两字段（"我刚用它干什么"原话 + 何时还会用）几秒记一笔，日后按自己的语境重现 |
| 全员 | 复制前不敢按、怕后果由我背 | **N3 敢按**：复制前看懂"动什么/改删什么/能否还原"+危险色，敢复制或敢不复制 |

底层三律：**被记住不是被教会 · 先有敢才有会 · 体面**（找回像"我本来就会，只是没带在手边"）。
口径：首发只做**通用 AI 答不出的个人/私有命令**；通用公开命令不预录。

## 3. 核心流程（一天的闭环）

```
【记一笔】刚学会/刚搜到 → 呼出 → 只填：我刚用它干什么(原话)＋何时还会用 → 存卡
【用话找回】干活卡壳 → Ctrl+Alt+P →
    ① 首屏：意图/最可能 1 条 + 备选 ≤3（永不空屏；空态引导记一笔或导历史）
    ② 输入人话/碎片 → 目的句+标题+别名加权命中
    ③ 卡面三行：动什么 / 改删什么 / 能否还原（探不到＝"无法探测"）+ 危险色
    ④ 取走：Enter=复制（high/critical 先弹确认"粘贴/执行前请再确认一次"）
    ⑤ 零命中 → 明示"没有这张卡" + 一键转记一笔（不许死胡同）
【自洁】用过记痕：30 天未用降权→60 归档→90 待清理候选；反复忘的置顶；试用的转正
【可观测】每步埋点 metrics.jsonl；本地可见
```

## 4. 数据模型（cards.jsonl）

字段（旧字段全保留，新字段纯追加、宽容读写、可回滚）：

| 字段 | 说明 | 必填 |
|---|---|---|
| id/product/title/aliases/kind/body/desc/tags/source | 原 v0.4 | ✓ |
| risk | low\|medium\|high\|critical（规则只判 high/critical=红；不判绿） | ✓ |
| **purpose** | 目的句：用户"我刚用它干什么"的原话（检索钥匙） | 记一笔时必填 |
| **rs** RiskScope | 动什么：本机/项目/全局/文件 | 记一笔时选 |
| **rm** RiskMutation | 改删什么：覆盖/删除/不可逆/无 | 记一笔时选 |
| **rr** RiskRevert | 能否还原：yes/no/unknown（unknown=无法探测） | 缺省 unknown |
| **rlabeled** RiskLabeled | 是否人工标注过（false=未标注→显示黄） | 缺省 false |
| fav/heat/copies(copyCount)/used/lastUsedAt/created/updated | 原统计 | ✓ |
| kind=command 追加执行统计 | exec/suc/fail/lastExecAt（进入执行能力后启用） | 后置 |

生命周期（试用态与自洁，惰性计算不加定时器）：`trial(新卡) →(被采纳/3 天复用) stable`；`stable→decay(30d)→archived(60d)→待清理(90d)`；收藏=fav 仅延缓衰减。

## 5. 界面规格（小窗）

- 顶部：产品切换 + 搜索框（占位="说一句你想干嘛…"）
- 首屏（空查询）：预测区＝最可能 1 条 + 备选 ≤3，标注理由（"最近用过/常用/上次成功"）；空库给引导行
- 结果项：title + purpose 摘要 + 危险色点（未标注=黄）
- 详情/卡面三行 + [复制]；high/critical 复制弹确认（文案见 §3）
- 底部状态行："今日：记 3 · 取 5"（可观测）
- 录入口：小窗内"➕记一笔"（两字段 + 可选风险三件）与后台编辑表单同一套逻辑

## 7. 验收

1. **自动**：Windows 上 `npm run desktop` → 编译成功 + SelfTest 全绿
2. **手工**：按 `docs/TESTCASES.md` 逐条执行（A/B 组已可测；C/D/E/F 随本版落地转为可测）
3. **试点生死线**（P0 成立判据）：C1 用话 30 秒命中 + C4 永不空屏 + F2 零命中出口——任一不过 = 收窄重审
4. 指标：唤出后 30 秒内有"取走动作"占比 ≥60%（样本 ≥50）——W4 试点门
