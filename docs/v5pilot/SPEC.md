## 一、定位（一句话）

> **一个"热键 3 秒重做上次"的行为记忆小窗**：不让你想起、不让你搜索——把你上次干成过的命令，按 Ctrl+Alt+P 的瞬间送到手边，回车复制走人。

回答的唯一问题："这事我上次干成过，那条命令是什么来着？"
明确不回答：第一次见的新错、从没存过的通用命令——那是 AI 的活，本工具不拦不抢。

## 二、场景与形态

**四幕（详见 DECISION 论证与讨论记录）**：
1. **撞同一堵墙**（P0 全押）：8080 被占 / 权限不够 / 服务起不来 → 热键 → 首屏"上次:今天 09:12"+ 完整命令 → Enter → 6 秒回现场。
2. **刚学会就留**：AI/同事给的命令跑通了 → 热键 → "剪贴板有条命令 → 回车存下" → 0 文本框；陌生来源才补问一句"干嘛的"。
3. **库自己长大**：启动时扫历史 → "你上周敲了 8 次，还没入库，收下？" → 回车。人不需要"想存"。
4. **边界**：零命中 → 灰字"去问 AI 或搜一下" → 自隐。不硬撑不打扰。

**形态**：托盘常驻图标 + 全局热键 `Ctrl+Alt+P` 唤出无边框小窗（约 520×360），一窗一框一个列表：

```
┌ Command Pocket ─────────────── 520×360 ─┐
│ 🔍 [敲字过滤…（可选）]              ➕   │
│ ────────────────────────────────────── │
│ ▶ netstat -ano | findstr :8080   ⛔危险 │ ← 置顶1·默认高亮
│   + taskkill /PID 17264 /F   上次:今天09:12│
│ ────────────────────────────────────── │
│   git push --force-with-lease   ⛔      │ 上次:周一
│   ssh deploy@10.0.0.5 'cd /app…'  ➕建议 │ 上周敲过8次·未入库
│ ────────────────────────────────────── │
│  今日: 取 3 · 存 1                       │
└────────────────────────────────────────┘
```

## 三、P0 功能全集（试点范围内全部）

| # | 功能 | 关键设计点 |
|---|---|---|
| F1 | 托盘 + 全局热键 | 常驻但不监听、无网络；`RegisterHotKey` 补返回值检查，失败提示回退点击托盘 |
| F2 | "再来一次"列表 | 排序 = 最近干成过(lastUsedAt) > 敲得勤(copies) > 最近存；置顶 1 + 备选 ≤5；**不是搜索，是排序** |
| F3 | 回车即走 + 危险门 | `Enter`=复制+自隐；high/critical 先弹"粘贴/执行前请再确认一次"，**只判红不判绿** |
| F4 | 打字子串过滤 | 记不全敲两字过滤（子串/别名），非搜索引擎 |
| F5 | 粘贴即存 | 热键手势内读剪贴板一次→单行命令形状判定→"存下?"回车即成卡；**0 文本框**；陌生来源才提示补一句人话；可关 |
| F6 | 首次历史导入 | **多源探测取最后写入者**（PSReadLine / Git Bash）→ 剔除口令/token/密钥 → 按频率 Top-N、保留原始大小写 → 新卡**不伪造使用时间**（不挤占真实"最近"）→ 结果明示来源文件与写入时间 |
| F7 | 高频提醒收录 | 每次唤出扫**最新源**历史找"高频未入库"（同频取最近出现）→提示收下；蓄水主力，无需"想存"动作 |
| F8 | 自动可懂性 | 机器嗅探类别(Git/网络/文件/进程)+危险词 → 列表小标签；裸命令自带一点上下文 |
| F9 | 本地流水 | 唤起/复制/放弃/存卡/Esc 各记一行 metrics.jsonl（本地可见可删）；试点数据源 |
| F10 | 手动 ➕ | 兜底：快捷键、GUI 步骤、同事口述等非命令知识 |

## 四、输入模型（锁版）

### 卡字段（绝不做"命令+用法都必填"表单）
```
命令      ← 自动带入（剪贴板/历史），唯一实质内容
一句人话  ← 可选，一键跳过；陌生来源才提示补；随时可后补
来源      ← 自动记录（历史/剪贴板/AI/手动），决定"要不要解释"
危险      ← 规则自动判红（high/critical），只判红不判绿
统计      ← lastUsedAt / copies / used（复用现有字段）
```

### 可懂性护栏（不看懂也敢复制，由三个机制保证而非文字）
1. **时间语境**：列表带"上次:今天/周一"——认时刻，不读语法；
2. **来源信任**：卡基本来自自己的历史/剪贴板，信任链=自己干成过；
3. **危险门**：会不会删东西由机器标红，不由用户阅读理解。

### 通道（蓄水主力 = 自动，存卡是副作用）
历史导入(一次) → 高频提醒收录(持续) → 粘贴即存(顺手) → 手动 ➕(兜底)

### 🟢 绿（设计即满足，代码审计时逐条核）

- [ ] 发布前 VirusTotal + 本机 Defender 实测；被误报时提供源码审计路径自证

### 🔴 红（分发信誉，试点≈0 成本，产品化才需解）
- [ ] 试点：本机跑，SAC/Defender 放行即可，不买签名
- [ ] 产品化（过线后）：三选一——Microsoft Store（免费签名）/ Trusted Signing（$9.99–99.99/月）/ OV 证书（$200–300/年）

### 结构性自证（Windows 无 TCC 授权门）
- [ ] 任何内容读取 = 一次用户可见手势 + 本地可查审计（peek 流水一行）
- [ ] 启动只驻托盘、不自动弹窗不读剪贴板
- [ ] 危险门**实时判定**：存储 risk 或现行规则命中任一即拦（防旧库缺省 low 的危险命令绕过确认）；只判红不判绿

### 真机验证点（开发后、试点前必过）
1. `npm run desktop` 编译 + SelfTest 全绿
2. **编译产物在本机 Defender/Smart App Control 实测**——不过关 → F5 改"粘贴式"（手动粘贴再存，零剪贴板读取）重试
3. PSReadLine 历史文件实际路径/编码/格式（PS5.1 与 PS7）
4. `Ctrl+Alt+P` 无热键冲突；DPI 125/150% 下小窗正常

## 六、技术要点与复用

另起**新的最小单文件** `native/CommandPocketPilot.cs`（已实现 ~1550 行：含旧库 jsonl 宽容解析器与内置 SelfTest，属必要成本；仍单文件、无第三方依赖），旧代码留 git 历史不删不动。

**验证路径**：Linux 容器内不做工具链安装，代码经静态审查 + Node 规则对拍（scripts/pilot-check.js）；编译与 UI 真机验证以 Windows `npm run desktop:pilot` 为准。

## 七、P1 / P2（试点过线前一律不实现，仅立项）

### P1 · AI 解释命令（用户拍板补充）
**目的**：补"可懂性"最后一块缺口——陌生来源（AI 教的/同事给的）命令裸存后想补课，或列表里某条眼生想弄懂。
**触发**：列表项上的显式动作（如 `?`/右键菜单"解释这条"），**永不自动**。
**行为**：本地无解释 → 配置了 LLM key 才可用 → 把该条命令文本发给 LLM → 返回一两行人话解释 + 危险提示 → 可一键存回该卡的人话字段。
**红线（遵守铁律：AI 仅 HTTP 可选、配 key 才启用）**：
- [ ] 默认关；设置里配 key 才出现入口；可全局关
- [ ] 命令文本出设备 = 一次显式用户动作触发 + 界面明示"将发送给 XX 服务"
- [ ] 请求内容不落本地日志；无 key / 断网时入口消失或灰置，本地能力全照常
**与其他项的关系**：它不影响 P0 任何判据；P0 生死线不依赖它。它默认关的属性使其不破坏"零网络"自证口径（审计清单注明唯一例外）。

### P1 · 报错现场第二入口（显式读剪贴板一次做签名命中，种子 15 条）
默认关；粘贴式先行攒一周数据，由数据放行读取；判死线同主场景。

### P2（仅记录方向，不展开）
卡面"三行风险"UI · 30/60/90 生命周期衰减 · purpose 语义检索（若打字需求出现按需回归加权内核）· 流水可见页。
