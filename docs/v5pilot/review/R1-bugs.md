# Command Pocket v5-pilot · R1 整体缺陷审查

基准：SPEC.md + CommandPocketPilot.cs 静态通读；已修项不回述；行号=现源码。

## 高

- **H1 历史导入整条命令被小写化** L694-716：`order` 存的是 ToLowerInvariant 后的 key，L714 `body=order[i]` 直接入库；大小写敏感参数（分支名/路径/环境变量值）被改写，复制即错命令。建议：去重计数用 key，入库用原始行。
- **H2 "ClipSave 永不默认选中"在空库态回归** L1185-1213：无 Card 行（空库/无匹配）时 first 恒 0，直接选中 Items[0]（ClipSave/Suggest）；空库+剪贴板有命令时单按回车即入库，且该行未过 IsSensitive（L1079-1086），口令类文本可一键误存。建议：无 Card 行时不选中或选中空行；粘贴行补 IsSensitive。

## 中

- **M1 jsonl 嵌套值提前终止整行** L268-296/344/363-366：未知 key 值为对象/数组时 SkipRawValue 遇首个 `,`/`}` 即停，行解析提前结束——后续 risk/purpose/body 静默丢失（body 在后整卡弃），读回再写盘时 risk 归 low，危险门被弱化。建议：按嵌套深度跳或至少扫到行尾。
- **M2 存储写盘无异常兜底** L627-682/646-656：LoadCards/SaveCards/Upsert/BumpCopy 均无 try/catch；磁盘满/文件锁/File.Replace 失败时异常直达 UI 线程，回车复制或启动即进程崩，.tmp 残留。建议：统一 catch+流水告警+清 tmp。
- **M3 无单实例保护** PilotAppContext：双开进程共用 cards.jsonl 与同名 .tmp，并发写会共享冲突、互丢更新。建议：Mutex 互斥。
- **M4 排序与规格/注释不符** L185-200：第三键为 Title 升序而非规格"最近存"；L541-549 同频恒返 0，List.Sort 不稳定，"按最近出现"落空。建议：第三键改 UpdatedAt 降序并稳定化。
- **M5 命中旧卡无条件覆盖 Source** L670：反复导入把 clipboard/manual 来源洗成 history，信任链失真。建议：仅原值为空才覆盖。

## 低

- **L1 失焦永不收起** L1362-1365：TopMost 小窗失焦/零命中后常浮顶，与场景四"自隐不打扰"相悖（代码注释为有意，仍建议复核）。建议：失焦即 Hide。
- **L2 读取点多且随库增长卡顿** L991/1081/1121：删空文本即重读剪贴板、每键全量重读 metrics、每次唤起重扫 ≤4MB 历史，超"手势一次"口径。建议：手势内缓存剪贴板与当日计数。
- **L3 热键失败不重试/多屏** L997/923：占用方释放后需重启才恢复；位置固定 PrimaryScreen，拔屏/DPI 变化可能出屏。建议：失败定时重试；Show 前夹取屏内坐标。
- **L4 解析边界** L395/412-426：`\u` 非法 hex 抛异常弃整行；超长整数溢出回绕为负 copies。建议：TryParse+非负钳制。
- **L5 过滤词跨唤起残留** L1058/1067：Esc 后不清 search.Text，重唤起显示旧过滤结果而非首屏，ClipSave 行被抑制。建议：唤起时清空。

## 最该先修的 3 条

1. **H1 导入小写化**——错命令入库复制，击穿"回车复制走人"主场景。
2. **H2 空库默认选中 ClipSave**——红线回归，敏感剪贴板内容可被单回车误存。
3. **M2 存储无异常兜底**——一次写盘冲突即崩托盘常驻。
