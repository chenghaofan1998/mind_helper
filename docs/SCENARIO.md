# Command Pocket · 场景交付 v2：「Logseq 够不着的地方」（行动现场快捷面）

> **取代 SCENARIO v1（"推不上去的三秒"，方向已否）。**
> 定位一句话：**Logseq 是你的大脑存档区，Command Pocket 是它伸到干活现场的那一页。** 大窗口交给 Logseq，Pocket 只做 Logseq 够不着的时刻——终端/IDE/任意应用前台、不想离开当前工作流的 3 秒取件。
> 形态（用户拍板）：小窗隐藏＋热键唤出。内容：**命令/快捷键优先，未来整个知识库都可被呈现**。数据：**Pocket 自库 与 Logseq 双向同步**。

---

## 一、场景（一天里的三种时刻，可演）

### 时刻 1 · 干活取件（Pocket 的日常）
终端里想不起 `git rebase` 的完整写法，按 `Ctrl+Alt+P`。打开的**不是空搜索框**，而是"此刻有货"的面：

```
┌ Command Pocket ─────────────────────────┐
│ 意图：撤销提交 ▾ 回滚 ▾ 推送 ▾ 查看历史…   │  ← 按"我想干嘛"翻，不用记名字
│ ─────────────────────────────────────── │
│ Git · 你常用的动作                        │
│ ▶ rebase 到指定提交          用过 12 次   │
│ ▶ 撤销已推送的提交           最近用过     │
│ ▶ 查看上次失败的命令          ⚠ 有风险提示 │
│ ─────────────────────────────────────── │
│ 🔍 搜：本库 + Logseq ｜ 📖 翻手册｜ ➕ 速存 │
└─────────────────────────────────────────┘
```
选中 → 复制 / 执行 / 若来自 Logseq → **回车直接"在 Logseq 打开"**（回源，上下文不丢）。

### 时刻 2 · 随手存（碎片有去处，不打断）
看到一条好命令/一个小技巧 → 热键 → `➕速存` → 选归属（哪个产品/哪个 Logseq 页面）→ 回车。**1 击成卡**。想长成文章？一键"送 Logseq"——它会在你指定的页面追加为一条 block，Pocket 不建第二个写作主场。

### 时刻 3 · 要 Logseq 里的东西（但不想切过去）
在任意应用里想查自己笔记里的某个方案 → 搜索框输入 → 结果区**双栏标注来源**：`[Pocket 速查]` 与 `[Logseq]` → Logseq 命中点"打开原文"直达对应块；也可以只取文本回复制。**Logseq 的内容第一次可以在不打开 Logseq 的情况下被消费。**

### 未来时刻 4 · 整个知识库的呈现（终局方向，分阶段）
打开 Pocket 不只是"查命令"，而是**"逛自己的操作知识"**：左侧是按产品/领域组织的树（数据 = Pocket 卡 ＋ Logseq 索引融合视图），每页像手册一样把命令/步骤/攻略/警告排开，每条带"用过几次·最近使用·健康度(会不会过时)"——**你攒了 3 年的东西是一本能翻、能续写、能送人的手册，而不是一个黑箱**。

## 二、解决方案（链路：问题→做法→技术）

### 1. 双库架构（本版地基）

```
Logseq 库(你的主场, markdown 文件)
   ▲ 只读索引(FileSystemWatcher+解析标题/代码块/列表)  ▲ 导出(追加 block, 需确认)
   │                                                 │
Pocket 自库(命令/快捷键速查卡, cards.jsonl, 毫秒级, 永远在线)
   ▲ 录入: 速存(1击) / 历史导入 / 种子库  ▲ 使用: 复制/执行/回源
```

- **写 Logseq 的方式**：文件级追加（`- ` block 语法）到你指定的页面，绝不改写既有内容、可撤销、可预览——不侵入 Logseq 内部结构，纯文件操作，安全；
- **读 Logseq 的方式**：文件扫描＋增量索引，只读不改；内容不进 Pocket 库本体，只进**索引**（锚点＝文件路径＋标题链/块），命中即"回源打开"；
- **防双写漂移**：同一知识只存一份——Pocket 卡可"认领"一条 Logseq 内容为来源（`sourceRef`）；搜到 Logseq 原文时不再复制一份卡。

### 2. 小窗三层 UI（打开即货，非空框）
- **意图层（默认）**：按"我想干嘛"分组（撤销/回滚/推送/压缩…），放最近与高频；这是"记不住名字"的解药——**用意图代替记忆**；
- **检索层**：本库＋Logseq 融合结果，来源双栏标注；中文/英文/报错片段都能搜（沿用别名与词表）；
- **动作层**：速查卡详情（何时用/风险/原文/来源）＋ [复制] [执行] [在 Logseq 打开]。

### 3. 动作能力（辅助，不是主角）
复制永远是默认；执行需显式（Ctrl+Enter）且过 S0 危险门（分级 0–4＋3 秒超时＋见习期）；退出码回写只影响"命令类"卡的排序。

### 4. 内容演进路线（你拍的第 4 点）
| 阶段 | 内容 | 呈现 |
|---|---|---|
| P1(现在) | 命令/快捷键速查（自库＋Logseq 命令类命中） | 意图层＋速查页 |
| P2 | 步骤/攻略/警告摘要 | 产品手册页（混排成文） |
| P3(终局) | **整个 Logseq 库可呈现** | 产品/领域树＋融合浏览＋健康度＋回源 |

### 5. 指标（可自证）
主：**唤出后 30 秒内产生"取走动作"（复制/执行/回源打开）的唤出占比 ≥60%**（样本 ≥50）；次：Logseq 回源点击率、速存后 7 天再取率（内容有没有真被用）、执行退出码分布。不猜"有没有用对"——只数看得见的动作。

## 三、准备（让这个场景成立，还必须做的）

### A. 数据准备
- 种子命令库（20–30 条高频动作，带风险分级）保证首日有货；
- 历史导入（PSReadLine/脱敏/试用态）——自库第一桶水；
- **Logseq 库接入准备**：路径配置向导（找到你的 graph 目录）→ 首次全量索引（标题/代码块/含命令的列表行）→ 后台增量监视；解析规则先覆盖 Markdown 语法（标题/围栏代码/列表），后续再谈 org-mode 与属性查询（Logseq 高级特性不追）。

### B. 基建准备（S0 三件套，先还债）
- 热键返回值检查＋Ctrl+Enter(执行) 第二热键；CommandStore 批量写；
- **危险确认门**（v0.4 欠账，代码已核实未实现）；
- 索引器/导出器的读写隔离：读只读、写必预览＋确认＋可撤销（导出 Logseq 前先展示将追加的 block 文本）。

### C. 安全与信任准备
- 默认零监听（延续裁定）；Logseq 索引只读不改你的笔记；
- 写 Logseq 属于"改文件"，纳入危险确认体系（新目的地/新页面追加默认预览）；
- 单文件无网络＝杀软自证材料，发布前 Defender/多引擎预检；
- 回源打开＝启动 Logseq 并定位（深链可用则用，不可用退化为"定位到页面＋高亮文本复制"）。

### D. 习惯与体验准备
- 首启 60 秒：预置演示卡跑通"热键→打开即货→取走"一次闭环，再引导接入 Logseq；
- **打开即货**是留存关键（空框=一次失败体验）；Esc/静音/暂停三层反悔照旧；
- 双入口引导文案一句话讲清分工："大而全在 Logseq，快而近在这里"。

### E. 验证准备
- SelfTest 扩充：索引解析夹具（标题/代码块/多级列表）、假时钟（试用态/遗忘）、危险门用例、导出预览用例；
- 埋点：唤出次数、取走动作类型、Logseq 命中→回源率、速存再取率——全本地 metrics.jsonl；
- **2 周试运行（你自己）判定线**：取走动作占比 ≥60%（样本 ≥50）＋ Logseq 回源周使用 ≥5 次 → 过则推进 P2/P3；不过则砍 Logseq 侧，退回"纯速查＋历史导入"攒数据再重审。

### F. 边界（明确不做）
- 不做大窗口知识管理（那是 Logseq）；不做第二写作主场；
- 不追 Logseq 属性数据库/复杂查询/插件生态——只用文件层；
- 不做自动推送/常驻监听（裁定保留）；执行能力只服务命令类卡。

## 四、卡点对账（新形态 × 已知卡点）

| 卡点 | 本方案 | 判定 |
|---|---|---|
| C0 注意力/打开率 | 寄生在热键＋干活现场；**录入主场在 Logseq**，Pocket 无需用户"专门管理"；打开即货消除空窗弃用 | ✓ 大幅缓解 |
| C1 唤起习惯 | 热键始终是唯一入口——缓解手段＝打开即货＋高频正反馈 | ◐ 诚实保留 |
| C2 验证黑箱 | 执行类用退出码；浏览类**不猜**（用户自选）→ 展示型天然降低验证依赖；指标只数可见动作 | ✓（降依赖） |
| C3 供给侧 | **Logseq 对接＝存量内容直接可呈现**（这是双向的最大理由）；Pocket 只需收"命令碎料" | ✓ 大幅缓解 |
| C5 索引质量(新) | Logseq 是笔记语言非结构化知识 → 高频动作靠 Pocket 结构化卡，Logseq 作全文兜底＋回源；语义鸿沟用回源闭环兜住 | ◐ 需 M3 数据 |
| C6 双库漂移(新) | sourceRef 认领＋导出预览＋不双写 | ✓ |

## 五、里程碑（每步可运行可回退）

| 步(周) | 交付 | 过/不过 |
|---|---|---|
| M0(1) | S0 基建＋schema＋种子库＋历史导入（Pocket 自库先通） | SelfTest 绿；脱敏生效 |
| M1(1.5–2) | Logseq 桥：接入向导＋只读索引＋融合搜索＋回源打开；导出器（预览确认） | 你库全量索引 <5s；回源定位准确率可接受；导出可撤销 |
| M2(1) | 行动面：意图层（打开即货）＋速查页＋复制/执行/危险门 | 预置卡跑通"想不起→打开→取走"全程 |
| M3(2) | 试运行＋判定线（见 E） | 过→P2/P3；不过→砍 Logseq 侧重审 |

> 一句话：**Pocket 不做第二个大脑，做大脑够不着时伸到手上的那一页；命令和快捷键先跑通，整库呈现是它长大的样子。**
