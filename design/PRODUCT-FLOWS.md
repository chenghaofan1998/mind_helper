# Action Pocket 产品流程与形态

## 1. 产品分层

### 小窗：高频、低摩擦

仅保留六件事：

1. 记录原始内容；
2. 用自然语言查询；
3. 显式截取当前问题并交给多模态模型分析；
4. 查看原文与必要上下文；
5. 复制命令或内容；
6. 打开原文或复制定位；卡片不展示固定、反馈或固定列表。

小窗不承担知识源配置、模型配置、索引管理和复杂编辑。

### 后台：低频、可解释

负责：

- 知识源连接与能力发现；
- 默认写入目标；
- RAG/检索模式状态；
- 全局热键与开机启动；
- 权限、隐私和审计事件；
- 未来观察能力的授权与状态。

## 2. 小窗状态

| 状态 | 触发 | 主操作 | 退出 |
|---|---|---|---|
| 隐藏 | 启动、Esc、失焦策略 | 无 | `Ctrl+Alt+P` 唤出 |
| 空闲 | 热键唤出 | 选择“记入/查询” | Esc 隐藏 |
| 记录 | 选择记入或带草稿唤出 | `Ctrl+Enter` 保存 | 成功后可隐藏；失败保留全文 |
| 查询 | 默认态 | Enter 查询 | Esc 隐藏 |
| 截图选区（P1） | `Ctrl+Alt+Shift+P` 或显式按钮 | 选区、本地预览、重选、确认发送 | Esc 销毁临时截图 |
| 截图分析（P1） | 用户确认发送 | 修改并确认建议问题，再查询知识库 | 返回预览或隐藏 |
| 结果 | 查询成功 | 上下选择、Enter 主操作 | 返回查询或隐藏 |
| 危险确认 | 复制高风险命令 | 明确确认后仅复制 | Esc/取消返回结果 |
| 离线/失败 | 知识源不可用 | 重试、打开后台 | 保留输入，不伪装成功 |

## 3. 输入模型

统一使用 `InputEnvelope`。当前版本已启用 `text`；下一版 MVP 启用用户显式触发的单次 `screen`，其他模态继续保留契约：

```ts
interface InputEnvelope {
  id: string;
  modality: "text" | "image" | "screen" | "audio" | "event";
  intent: "capture" | "query" | "observe";
  content?: string;
  attachments?: AttachmentRef[];
  sourceContext?: SourceContext;
  consent: ConsentReceipt;
  capturedAt: string;
}
```

设计规则：

- 大文件或图像只传引用、摘要和哈希，不在 JSON 中塞 Base64。
- `capture`、`query`、`observe` 是不同意图，不能静默互换。
- 输入失败时保留用户原始内容。
- 来源上下文只用于当前任务；是否写回必须再次确认。

## 4. 输出模型

输出分为三层：

### Observation：多模态模型观察

- 截图中可见的事实与 OCR 文本；
- 对应图像区域和可选置信度；
- 建议问题与敏感信息提醒；
- 明确标识为模型推断，不冒充知识库原文。

Observation 默认只作为构造 RAG 查询的临时上下文，不自动写入知识库。

### Evidence：知识库原始证据

- 原文摘录；
- 必要前后文；
- 文档/块标识；
- 版本；
- 可打开的原文 URI；
- RAG/rerank 分数及检索模式。

### Derived：按当前任务转换的结果

- 命令；
- 步骤；
- 检查清单；
- 简短解释；
- 冲突与知识缺口。

`Derived` 必须引用一个或多个 Evidence，且界面不能把它显示成原文。

## 5. 热键设计

默认热键：普通入口 `Ctrl+Alt+P`，一次性截图 `Ctrl+Alt+Shift+P`。

- `Ctrl+Alt+P`：显示、置顶并聚焦输入框；
- `Ctrl+Alt+Shift+P`：进入区域/窗口截图，完成后打开预览；
- 窗口已显示时再按：隐藏，不新建重复窗口；
- `Esc`：关闭模态、取消并销毁截图，或隐藏窗口；
- `Ctrl+Enter`：记录态保存；
- `Enter`：查询态提交/结果态执行主操作；
- `↑↓`：结果选择；
- 热键注册失败：托盘气泡明确提示，托盘点击仍可打开；
- 不使用键盘钩子，不记录用户按键。

## 6. 未来观察能力

只预留 `observe` capability，不在 MVP 启用（本轮不实现，见 `IMPLEMENTATION-NOTES.md` 09）。

未来流程必须是：

1. 用户从后台选择数据源和应用范围；
2. 系统显示采集内容、处理位置、保留时间和停止方式；
3. 用户显式开始会话；
4. 小窗/托盘持续显示“观察中”；
5. 用户可随时暂停或停止；
6. 默认只产生本地结构化事件，原始屏幕帧不长期保存；
7. 写入知识库或发往云模型需要独立确认和能力授权。

禁止把“未来可能做”变成当前的全量监听。

## 7. MVP 验收

- 热键到可输入时间目标 <300ms（真机测量）。
- 记录成功必须得到知识源回执；失败原文不丢失。
- 抽象查询交给支持 `rag` 的知识源，平台不偷偷降级后冒充 RAG。
- 每条结果都有原文、上下文、定位和版本。
- 危险命令只复制不执行，并在复制前确认。
- P0 允许通过环境变量配置单一来源，并在小窗显示来源与实际检索模式；后台配置页是后续低频配套，不阻塞 P0 闭环。
