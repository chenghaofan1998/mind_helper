# 实现注记：原型图是探索素材，不是验收清单

> 本文对 `generated/gpt-image-2/` 的 10 张原型图逐张给出「保留 / 简化 / 不做」结论，用于防止照单实现。
> 依据：`gpt-image-2-prompts.json` 的分镜定义与 `ui/*.svg` 结构稿（分镜定义与成图不一致时，以本文「保留」列为准）。
> **阅读顺序：先读本文，再看图。图为语言与层级参考，不作为像素级还原目标。**

## 一、结论

1. **这 10 张图按原样实现会做出一个"知识中台"**，而纲领要的是一个能 3 秒记一笔、问一句的小窗。
2. **首版只做 4 个画面**：快速记入（01）、查询（02）、结果（03）、危险确认（04）。
3. **截图能力作为第二个闭环**，但只做"选区 → 预览 → 一句话 → 查询"，不做编辑器和模型路由。
4. **立即砍掉 4 项**：`observe` 观察能力、region 级引用、Derived 派生层渲染、后台能力矩阵与架构图页面。
5. 如果只允许保留一张图严格实现：**03 结果图**。它承载"原文优先、来源可查、只复制不执行"三条红线。

## 二、复杂度对照

| 维度 | 原型暗示 | 建议首版 | 差额原因 |
|---|---|---|---|
| 前端状态 | 10+ 屏（含后台 4 页、观察授权、架构图） | **6 个状态** | 后台与架构图不是界面需求 |
| 后台页面 | 6 个导航项 | **1 页**（连接器 + 测试连接） | 低频配置，够用即可 |
| capability | 8 项全实现 | **实际调用 3 项**：`search` / `write` / `vision-analysis` | 其余声明保留、不驱动 UI |
| 输出层 | 3 层（Observation / Evidence / Derived） | **渲染 2 层**，Derived 只留字段 | 派生内容易与原文混淆 |
| 连接器类型 | 3 类 | **2 类**，`combined` 只留字段 | 首版无需合并型适配器 |
| 热键 | 2 个 | 2 个（保留） | 独立截图热键是隐私红线的实现方式，成本低 |

## 三、逐图注记

### 01 快速记入

| 项 | 内容 |
|---|---|
| 保留 | 原始内容输入区；写入位置可见可改；`Ctrl+Enter` 保存；**成功才清空、失败保留全文** |
| 简化 | 删除"纯文本""用户显式输入"等自证标签（零信息）；写入位置由默认值预填，不用下拉框 |
| 不做 | 富文本、标签选择、场景/分类选择、附件 |
| 理由 | 首版只有一种输入形态，标签与选择器都是空转 |

### 02 RAG 查询

| 项 | 内容 |
|---|---|
| 保留 | 单个问题输入框；**真实检索模式用一行文字标注**（如"本地词法检索，未使用 RAG"） |
| 简化 | 来源健康徽章 → 一行文字；"你也可以问"示例卡 → 删除，改用输入框 placeholder |
| 不做 | 模型选择、检索参数面板（top-k / rerank 开关）、多来源并列选择器 |
| 理由 | 检索归知识库；平台不暴露调参，也不能把词法结果说成 RAG |

### 03 结果（唯一必须严格实现）

| 项 | 内容 |
|---|---|
| 保留 | 原文摘录；必要前后文；路径 + 行号 + 版本；`复制原文`；`打开原文`；`固定`；`有用` |
| 简化 | 不显示相似度分数（跨实现不可比）；页面最多 5 条，默认只高亮 1 条 |
| 不做 | 派生建议层渲染、相似度条、"没解决"负反馈按钮、追问对话 |
| 理由 | 纲领要求"少量可用结果 + 原文入口"；负反馈等有真实需要再加 |

### 04 危险命令确认

| 项 | 内容 |
|---|---|
| 保留 | **整张保留**：只复制不执行、默认焦点在"取消"、`Esc` 关闭、焦点不逃出模态 |
| 简化 | 规则只判红不判绿，不做风险等级分级展示 |
| 不做 | 无 |
| 理由 | 安全红线，实现成本最低、收益最高的一张图 |

### 05 截图选区

| 项 | 内容 |
|---|---|
| 保留 | 独立热键触发；区域选择；预览；确认后才发送 |
| 简化 | 去掉涂抹/马赛克编辑器，改为「重选」；工具栏只留 `重选 / 取消 / 使用` |
| 不做 | 自动存盘、自动识别后直接检索、多显示器与窗口枚举、原图落盘 |
| 理由 | 首版只需"选一块、看一眼、发出去"；遮挡请用户在截图前自行处理 |

### 06 截图分析

| 项 | 内容 |
|---|---|
| 保留 | 截图缩略图；可编辑的问题文本；一个主按钮（发送并查询） |
| 简化 | 合并"仅分析 / 分析并查询知识库"为单一动作；数据去向与保留策略用一行小字，不做图示 |
| 不做 | region 级引用高亮、OCR 分区展示、多模型路由选择、模型挑选用户可调 |
| 理由 | 首版链路只需「截图 → 一句话 → 查询」 |

### 07 后台连接器

| 项 | 内容 |
|---|---|
| 保留 | 名称、地址、`测试连接`、默认写入位置、删除、capability 一行 chips |
| 简化 | 健康 / 索引新鲜度 / 处理位置 / 保留策略面板 → 合并进「测试连接」的即时结果 |
| 不做 | 能力矩阵表单、多连接器编排、凭据填写 UI（用环境变量或系统凭据库） |
| 理由 | 后台是"配好一次"的低频页，不是管理台 |

### 08 小窗与后台形态 · 10 输入输出架构

| 项 | 内容 |
|---|---|
| 保留 | 仅作文档与沟通材料 |
| 不做 | 不做成界面；不实现架构图页面 |
| 理由 | 它们是说明图，不承载用户任务 |

### 09 观察授权

| 项 | 内容 |
|---|---|
| 保留 | 归档为未来设计，保留接口字段 `observe` |
| 不做 | **本次不实现观察会话**：不做采集、不做事件流、不做采集审计页 |
| 理由 | 纲领 §6 明确"不默认读取剪贴板、屏幕、键盘"；无真实需求前做监控等于自找合规风险 |

## 四、三处最容易做过头

1. **后台能力矩阵**：把 8 项 capability 做成可勾选表单 → 实际只需要"能不能用 + 测试连接结果"。
2. **截图分析**：加入模型选择、区域引用、OCR 分区、双模式按钮 → 实际只需要一次分析、一段可编辑问题。
3. **多层输出**：把 Observation / Evidence / Derived 都渲染成等权卡片 → 实际只渲染 Observation 与 Evidence，且 Evidence 必须在视觉上更重。

## 五、分阶段与验收

### P0（本迭代，一个完整闭环）

链路：热键开小窗 → 记入 → 查询 → 结果 → 关闭。含危险确认。

- 热键到可输入 < 300ms（真机测量）
- 写入失败时原文不丢失，且不显示成功
- 每条结果必带来源路径、行号、版本
- 危险命令复制前 100% 拦截
- 单来源默认，无来源时明确提示而非静默失败

### P1（第二个闭环）

链路：截图热键 → 选区 → 预览 → 分析 → 联合查询。

- 取消截图后临时图像即销毁
- 发送前可预览并可见数据去向
- 无 `vision-analysis` capability 时入口明确禁用
- 模型观察与知识库原文视觉分层

### P2（需真实数据支撑后再做）

固定与有用反馈、遮挡编辑、多来源切换、Derived 渲染、负反馈。

### 明确不做（本轮）

观察会话、架构图页面、能力矩阵、凭据管理 UI、多模型路由、自动写回知识库。

## 六、不能以"简化"名义违反的红线

| 红线 | 对应实现 |
|---|---|
| 不默认读取剪贴板 / 屏幕 / 键盘 | 截图必须独立热键 + 预览确认，禁止静默采集 |
| 内容以知识源为准，不另建正文库 | 平台不缓存正文，固定与反馈只存来源引用 |
| 只复制不执行 + 危险确认 | 04 图必须实现，含模态焦点管理 |
| 不默认重新生成回答 | 结果页原文优先，Derived 不得抢占主位 |
| 检索模式必须诚实 | 词法降级必须显式标注，不得暗示为 RAG |

## 七、行动建议

**先实现 01 / 02 / 03 / 04 四个画面并跑通真实知识库，其余图留在 `generated/` 只作参考。**
截图链路在 P0 验收通过、且真实使用中确实出现"问题就在屏幕上"的频次后，再启动 P1。
